# IMPERIA COLD WAR: Israel V2 independent generic-core review

Scope: the root compiler's complete in-memory native payload, including the 153 generic actions. The 13 domestic special actions, recipient agreements and territorial actions have separate owners and are excluded from the generic compiler. This review did not edit `runtime_core.py` or `compile.py` and did not install their output.

## Findings and corrections

| Finding | Observed consequence | Verified correction |
|---|---|---|
| Whole availability predicates were hidden | Ownership, private finance and actual war/emergency requirements disappeared from native focus tooltips | Separate truthful `visible_available` predicates retain material conditions while execution guards remain hidden and rechecked |
| Variable modifier previews lacked explicit native tooltip bindings | Created `$RIGHT$` formatters were not explicitly connected to the native variable-change effect | Each preview modifier uses `tooltip = <mapped variable>` with the appropriate native formatter |
| Poalei's workshop project certified its own governing representation | Four projects depended on a self-issued persistent political flag | The false representation flag is removed; a disclosed runtime overlay describes paid cooperative contracts under the actual governing orthodox party |
| Late invalidation and duplicate completion shared one failure path | A duplicate call could delete an already valid focus badge | Failed new transactions reopen only their own focus; existing successful receipts are no-ops |
| Native capacity needed more than completed-building variables | Queued construction could exhaust the actual remaining capacity | Native slot/capacity predicates are checked alongside owner/control and hard level caps |
| HaOlam detention review lost its controlled non-core requirement | The policy could execute without any controlled non-core territory | A native `any_controlled_state = { NOT = { is_core_of = ISR } }` predicate is visible and rechecked by the actual transaction |

No additional unresolved generic-core finding remained in the final eleven-test run. This does not certify native rendering or the entire game integration.

## Source-driven regressions

`python tools/israel_v2/test_runtime_core.py` passes eleven tests against the actual complete `compile.build()` output. It verifies:

- The 153 generic action owners exclude all domestic and bilateral special-action IDs.
- All 39 generic building focuses execute once, grant exactly one shared slot per building level and do not repeat assets or costs on a duplicate call. The slot grant precedes construction inside the same native state block.
- A late loss of control or queued-capacity veto reopens the focus without charging money, setting the success receipt or creating an asset.
- The three compatible workforce reforms reach exactly +15%. A duplicate completion cannot increase that total or repeat their costs.
- Removing the absorption starting spirit does not add a second positive research/social-cost relief on top of removing its penalties.
- A party's programme deactivates on departure and returns without replaying costs. The wage programme expires at 365 days; the 53-week renewal reopens separately and pays its debt cost again.
- Focus-specific quoted costs remain distinct. With a tank coupon, the fixture's current-GDP prices are 0.11 billion for Tal's tank project and 0.18 billion for Nesher. Repeated quoting consumes neither the coupon nor restricted funding balances.
- Native focus previews remain in non-executing `effect_tooltip` blocks, and every variable-backed modifier preview has an explicit native numeric formatter.
- Editorial title compaction changes only `label` and `full_label`, remains idempotent and preserves every other field.
- HaOlam's policy rejects a world fixture with no controlled non-core territory, then succeeds when actual control returns.

The test interpreter consumes generated native effect bodies rather than a parallel reward implementation. It models the inspected Treasury/debt consumers, receipt flags, party predicates, timed-country-flag expiry, state ownership/control and explicit built/queued capacity. Native research, doctrine, faction and corruption commands are recorded rather than simulating their complete host systems. Random-state selection uses a deterministic fixture rather than the engine RNG. Native shared-slot unlock rules, engine queue semantics, graphics, save/reload, rehosting and multiplayer timing remain outside this model.

## Native provider references

All ten research categories actually used by the generic actions are assigned to live technologies: agriculture, aircraft, armour, corvettes, electronics, industry, medium aircraft, military electronics, nuclear reactors and nuclear weapons. Relevant consumers exist in the current `industry.txt`, `engineering.txt`, `armor.txt`, aircraft files, `naval.txt`, `ballistic_missiles.txt` and the loaded Cold War technology additions. Current native Israel focus examples also use `add_doctrine_cost_reduction` with `category = land_doctrine`.

Native modifier preview grammar was checked against `05_russia.txt` and `MD_dm_modifiers_l_english.yml`. Decreasing supply consumption, army training time, incoming-investment costs and interest rates uses inverse-benefit colouring. Interest rates use the native decimal formatter and explicit percentage-point wording. Existing country modifier providers were found for compliance and garrison damage. The special Home Front effect uses a separate native unit-technology provider rather than an unsupported country-level casualty modifier.
