# Mechanics revision v2 addendum

This note tightens the unit scope and GDP amounts in `mechanics_revision_v2.md` against the loaded MD sources. It is a concept audit only; no game scripts or the canonical design were changed.

**Artillery needs unit-specific modifiers where the focus promises a direct battalion combat gain.** The active towed battalion `Arty_Bat` declares `type = { artillery }` and `category_artillery` at `common/units/MD_land_units.txt:1256-1273`. Self-propelled artillery `SP_Arty_Bat` declares `type = { armor artillery mechanized }` and `category_artillery` at `:1304-1324`; rocket artillery `SP_R_arty_Bat` instead declares `type = { armor rocket mechanized }` and `category_artillery`/`category_mlrs` at `:1356-1376`. Therefore the national `army_artillery_attack_factor` follows the artillery type: it covers `Arty_Bat` and `SP_Arty_Bat`, but not `SP_R_arty_Bat` (its artillery category does not change its `rocket` type). The modifier registry explicitly provides attack and defence modifiers for all three at `common/units/unit_modifiers/unit_modifiers.txt:104-115`. For the Artillery Concentration reward, use the registered keys `modifier_army_sub_unit_Arty_Bat_attack_factor`, `modifier_army_sub_unit_SP_Arty_Bat_attack_factor`, and, if rocket artillery is part of the promise, `modifier_army_sub_unit_SP_R_arty_Bat_attack_factor`; use the corresponding `_defence_factor` keys only if the text promises protection. `SP_AA_Bat` has its own separate registered keys at `:116-119` and is not covered by an artillery-only promise. The national key is natively used by MD (`common/ideas/05_france.txt:1244`, `common/ideas/05_netherlands.txt:433`); exact subunit keys offer more precise scope where needed. A generic `army_attack_factor` affects too broad a force.

**Air Defence Commands should not use `air_defence_factor` as an interception bonus.** Its native uses are air-force ideas (for example `common/ideas/05_netherlands.txt:431`), while air interception detection has the explicit supported key `air_interception_detect_factor` (`common/ideas/Algerian.txt:2504-2540`; also `common/ideas/Bolivian.txt:547-578`). Use `air_interception_detect_factor` for interception detection/readiness. Use `air_detection` for broad detection or radar warning coverage (`common/ideas/05_netherlands.txt:432`). Reserve `air_defence_factor` for an aircraft-defense stat effect; do not describe it as land AA damage, static AA hit chance, or interception efficiency. For land AA, use the static-AA keys `static_anti_air_damage_factor` and `static_anti_air_hit_chance_factor` (native pair at `common/ideas/05_china.txt:1805-1814`).

**Keep all construction costs and the legacy loan quote GDP-relative.** NKO’s 1970 calibration target is 5.781 in the scenario display scale (`common/scripted_effects/IMP_1970_gdp_scripted_effects.txt:1771`), and the GDP calibration converts target GDP to the internal `gdp_total` scale by multiplying by 3.4 at `:1831-1833`. Thus the calibrated start is approximately 19.6554 internal GDP units; 1.5% is 0.294831 internal units (about 0.295 billion on the economy’s internal cash scale). Replace the old fixed 7.5 billion principal with a saved quote equal to `0.015 * gdp_total` at offer time, and display that calculated amount in the offer and repayment terms. Do not later recompute principal from a changing GDP value. For focus projects, use a single proportional charge in the 0.1%-2.0% GDP range (`treasury_change = { value = gdp_total multiply = -0.001 }` through `-0.02`, then `modify_treasury_effect = yes`); native focus examples confirm the calculation pattern (`common/national_focus/00_generic.txt:2019` for 0.1%, `:247` for 1.5%, and `:625` for 0.5%).

**Every building level granted by a focus must also add one shared slot in the same state.** This includes radar, infrastructure and energy buildings, even if the selected building does not itself consume a shared slot. Pair each state-scoped building increase with an equal `add_extra_state_shared_building_slots` increase, following MD’s state-scoped pattern (`common/scripted_effects/00_internal_investment_automation_effects.txt:76-88`).
