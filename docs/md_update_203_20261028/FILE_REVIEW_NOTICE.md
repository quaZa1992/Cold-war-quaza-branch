# IMPERIA COLD WAR: Individual MD update review provenance

The individual review and `file_review_preview.png` are generated from the 73
verified source-delta records in this directory. They are a read-only comparison,
not an in-game screenshot and not an applied migration. The screenshot is a
browser composition of text and controls; no third-party artwork is embedded.

The current-file text and diff excerpts retain the authorship of Millennium Dawn
and the existing Cold War/Imperia contributors. Individual authors and separate
redistribution permissions are unknown where the inherited source does not
identify them. Existing licences and project notices remain authoritative.
The German explanations and review tooling were authored with Codex for this
conversation. No game localisation, active source file or binary asset was
modified. Presentation selection records the file being examined, never approval
or an instruction to change the mod.
