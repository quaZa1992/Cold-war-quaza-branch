MD Cold War: Focus Quality Audit

5469 focus definitions inventoried15 focus files16 findings

The added trees do not yet consistently meet the agreed standard. There are substantial, differentiated programmes, but also conditional empty rewards, overstated financial benefits, ceremonial padding and unfinished player-facing descriptions.

No gameplay or localisation files were changed. Every listed tree was included in the source inventory; deep mechanics checks cover representative routes and documented findings, not every possible modifier or game state.

What should change first

  • Repair confirmed conditional reward losses and incorrect numeric presentation.
  • Remove developer scaffolding from English descriptions and hide internal routing checks.
  • Merge or strengthen demonstrably redundant PP-only/empty gates, preserving meaningful political choices.
  • Review each compatible whole route against native MD and the1970 starting economy; verify caps, faction presence and cleanup.
  • Run representative new-game, tooltip, party-change, save/reload and multiplayer checks before calling the work validated in-engine.

Duration and depth

Longer is not automatically better. In installed main MD2.0.2,314 of806 Russian focuses use cost3 (~21base days). Israel also uses many14/21day focuses. A35-day node with a meaningful policy can be preferable to a70-day receipt. Do not extend every short focus or impose a minimum description word count.

Tree counts include mutually exclusive parties and shared content. They are not the number of focuses a country can complete in one compatible route. Actual campaign pacing and timed spirit refreshes need game tests.
