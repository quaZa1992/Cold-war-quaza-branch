# Fidel/PCC expansion mechanics review

This is an evidence-led review of the emitted Fidel/PCC additions: Family Code, family doctor and nurse coverage, the Havana biotechnology programme, the 1980 market reforms, and microbrigades. It treats the proposal as a 1970–1990 Cold War concept and uses the current workspace and installed main-MD files as API evidence. The emitted model was statically validated at 120 focuses; mechanics and route totals below refer to that model.

## Healthcare initialization is unresolved in the 1970 start

The Cuba country-history `1970.1.1` block sets politics and scenario variables, but does not add `health_01..health_06` or `edu_01..edu_05`. The `health_02` idea occurs in Cuba's later `2000.1.1` history block. The searched current `common`, `history`, and `events` script sources do not show a global idea-initialization call that would create those budget ideas for Cuba before the focus is available. The arrays declared in `common/scripted_effects/00_money_system.txt` are law-option registries, not country initialization. The separate concept setup in `tools/cuba_1970_concept/lifecycle.py` proposes adding `health_02`, `edu_02` and `corruption_level_04` only where each category is genuinely missing, but this is still a design proposal, not current runtime behavior.

Consequently, native `increase_healthcare_budget` is unsafe on the current uninitialized Cuba baseline: `common/scripted_effects/00_budget_effects.txt` checks existing `health_01` through `health_05`, then grants 150 political power in its `else` branch. It does not establish `health_01` or increase a budget when no tier idea exists. The safest concept contract is to implement the proposed, one-time missing-category setup and to require a valid health idea in both availability and reward; if that setup is not implemented or the category remains missing, leave the focus unavailable/pending and show the initialization requirement. Do not call the vanilla helper speculatively or let its fallback grant PP. If custom code is later chosen, availability and reward must both guard the same initialized baseline; the completion reward must revalidate before charging money or adding a tier.

## PCC route balance and native-MD comparison

The emitted model validates at 120 focuses, 17 programmes, and 13 governing programmes with no static validation errors. The PCC branch has thirteen entries. Each compatible full PCC route contains ten focuses: one of Party Ministries/JUCEPLAN and one of SDPE/Rectification are selected, and the chosen economic route makes the other endpoint (Peasant Markets or Revive Microbrigades) unreachable. The latter pair is not declared mutually exclusive, but its parent route gates it. Cuban Socialism accepts either endpoint. The four enumerated terminal paths therefore each contain ten focuses rather than eleven. PCC-only route totals are 378 focus-days and Treasury −2.05 through either Party Ministries or JUCEPLAN → SDPE → Peasant Markets, or 392 focus-days and Treasury −2.30 through either governance option → Rectification → Microbrigades. Totals include existing PCC foci as well as the new nodes; they do not mean the selected foci can run simultaneously.

The refreshed `BALANCE_REVIEW.md` and `BALANCE_RANGES.json` (both timestamped 23 October 2026, 15:33:11) report 7,168 compatible mature configurations across 256 common routes and 13 governments. PCC ranges include workforce +3% to +11% and research speed +2% to +11%; the same audit reports healthcare expenditure +23% to +37%, welfare expenditure +6% to +11%, and education expenditure +34%. These ranges include new-focus and starting-spirit modifier deltas plus modeled mature replacements, but exclude native budget-tier costs, cap fallbacks, influence calculations, events, and temporary crises as the balance report states. The Family Doctor modifier combines with Rural Clinics when selected: healthcare workforce requirement ranges −6% to −14%, so its effect should not be described in isolation from the shared branch. These generated audits are current for the emitted model; the 7,168 count is a combinatorial comparison, not an in-game economy result.

Installed native main-MD Cuba is a useful presentation comparison, not a valid 1970 budget baseline. In `E:/SteamLibrary/steamapps/workshop/content/394360/2777392649/common/national_focus/05_cuba.txt`, its healthcare and education budget focuses cost 5 (35 days); Cuba's infrastructure investment follows three economic/service investments and uses the native `one_random_infrastructure` reward. Native `CUB_battle_ideas` also reuses the `cubabattleofidea` image identifier, but the concept's starting spirit must use actual idea art instead of a focus icon alias. The main-MD branch is 2000-era; it does not override the separate 1970 history initialization finding above.

## Remaining implementation checks

The rendered excerpts use real focus icons and clearly distinguish one-time treasury costs from recurring weekly modifiers. One-time literal amounts are ≤5 decimal places. The exact health_02 initialization still exists only in concept setup, and all new completion receipts/dynamic modifier application are design-contract comments rather than installed runtime code. Treasury debits use the native direct-add helper, which neither checks affordability nor caps the deduction at current cash; the concept should say “Treasury −X” as an effect, not imply the reward is conditional on an affordable cash balance. Run a new 1970 game session after implementation to verify setup order, healthcare-tier changes, cap efficiency, and actual weekly budget changes; the current artifact is a concept export, not an in-engine test.
