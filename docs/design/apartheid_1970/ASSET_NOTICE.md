# IMPERIA COLD WAR apartheid preview and icon provenance

`FOCUS_PREVIEW.html` and `FOCUS_PREVIEW.png` are original diagrams generated by `tools/apartheid_1970/preview.py` from installed focus coordinates and descriptions. They are layout previews, not game screenshots. No third-party images are embedded in those diagrams. Font: the locally installed Microsoft Arial font, used for rendered text; font redistribution permission is not established and no font file is distributed.

The dynamic spirit reuses MD's registered `GFX_idea_segregation`, whose texture is `gfx/interface/ideas/diplomacy/segregation.dds`. Original author and applicable image licence or permission are unknown. The source sprite is retained unchanged. The inspected conversion at `docs/design/APARTHEID_ICON_REVIEW.png` is a lossless PNG-format review copy of that 60 x 68 texture, with no visual edits. No ownership claim is made for that artwork. Refer also to the repository's `IMPERIA_COLD_WAR_NOTICE.md`.
