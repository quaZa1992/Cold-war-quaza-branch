# Runtime GDP preview provenance

`runtime-preview.html`, its template and the `runtime-preview-qa.png` browser capture reuse the embedded native focus art from the approved `COLDWAR_ARG_preview.html`. Source assets, hashes, original credit where known and modifications are recorded in `PREVIEW_PROVENANCE.json` and the runtime design's `art_sources` records. Individual original artists and separate redistribution permissions are unknown unless those records say otherwise. See `IMPERIA_COLD_WAR_NOTICE.md` at the project root. No ownership claim is made for Millennium Dawn or underlying game artwork.

The revision changes monetary calculations and finance controls to use the installed GDP cost schedule. Positions, icons and non-monetary rewards are preserved. The capture is a browser-composed review image with approximate font and connector routing, not an HOI4 screenshot. GDP fields are editable estimates; actual in-game costs use the countries' live native GDP.
