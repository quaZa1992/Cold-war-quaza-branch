## Scope and evidence

This read-only review covers `tools/argentina_1970/treaties.py` and its seven in-memory outputs from `tools/argentina_1970/approved_design.json`. The approved source SHA-256 matches `tools/argentina_1970/APPROVAL_RECORD.json`: `bbfa7337ba2677c7f3939a09e1aa3b456caad8966dbf8d03369d262483006012`. The generator returned 20 unique agreements. All six generated Clausewitz script/GFX-free source files parsed with the project's `tools/vietnam_1970/script_ast.py`; localisation was not passed to that script parser.

The live tree integration, native effect execution, tooltip rendering, decision visibility, daily/weekly refresh timing, save/reload, and engine log are outside this source-only pass. The core integration is still pending, so this is not a final loaded-runtime audit.

## Mechanics reviewed

- Both directions require the partner to exist, mutual peace, no native embargo in either direction, and no entry in any of the four mirrored Imperia sanction classes for either country. The source checks all eight current arrays with `is_in_array` in the corresponding country's scope. This matches the current mod's native array usage.
- Pending flags are set on Argentina and the named recipient for 90 days. The recipient has separate accept and decline decisions. Argentina's retry decision is available after its 180-day cooldown, and the initial offer is made by its named national focus. A standing signed treaty uses non-expiring signed flags; the active trigger suspends/restores spirits through the shared conditions.
- Acceptance wraps the current consent, pending, not-signed, pair-clear, parent, territory, history, and building checks around both setup costs, any compensation, buildings/slots, research bonuses, transfer, flags, and ideas. The refusal path only clears pending flags. No positive-treasury or cash-balance gate appears in these transactions.
- The display helper previews each side's setup payment, signed modifier values, recurring weekly payment/income, named ideas, research bonuses, construction and extra slots, and the UK sovereignty transfer. The same guarded helper powers the accept transaction. In the approved snapshot, the only construction grants are one infrastructure level each in State 453 (Argentina), 893 (Uruguay), 450 (Argentina), and 468 (Chile). Their execution/display pairs grant one shared slot per level. The state-scope guards require ownership/control, check the native infrastructure state cap of 6, and do not require shared slots for infrastructure.
- Current custom country modifier definitions include the Imperia keys used here, including `foreign_influence_defense_modifier`, fiscal/education/health/social cost modifiers, and `agricolture_productivity_modifier`. Other keys appear in current MD country ideas/focuses. The three research categories used by the agreements (`CAT_industry`, `CAT_nuclear_reactors`, `CAT_aircraft`) are used by current MD technologies and native research effects.
- The UK sovereignty transaction rechecks ENG ownership/control of state 26, requires the UK leaseback parent spirit, charges each side once, pays the approved 5 billion treasury credit to ENG, transfers state 26 to ARG only after recipient consent, and adds no core.
- Generated localisation separates event `.t`/`.d` keys from `.a` options, remains English, and translates no implementation text into player-facing descriptions. Agreement notifications contain a review option; the separate recipient decisions carry the prospective acceptance effects.
