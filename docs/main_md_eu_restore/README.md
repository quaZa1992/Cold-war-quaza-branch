# Main MD EU system restored

Current state: all custom CWEC and MD1970 EU adaptations were removed at the user's explicit request on 18 October 2026.

The EU uses the main Millennium Dawn interface, proposal catalogue, Parliament, Council, elections, AI participation, office rules, membership modifiers and budget logic. The original `99_eu_scripted_effects.txt` was copied directly from the read-only Workshop installation, including its original euro logic. No historical euro restriction from the custom work remains in that EU script.

Nineteen native files were checked byte for byte against the main MD mod. Shared economy, on-actions and money localisation files were restored from the verified pre-extension backup, preserving their unrelated Cold War changes. All 73 recorded unrelated local files retained their current hashes. Original Workshop files were not modified.

All custom runtime scripts, localisation overrides, cosmetic flags and the tools capable of reinstalling the adaptation were archived and removed. A scan of the active common, events, interface, localisation and history directories finds no CWEC, MD1970_EU, MD1970_EC or GetMD1970EU references.

The exact inventory and backup path are in [restore_report.json](restore_report.json). Previous implementation and validation documents are historical records, not descriptions of the active mod.

Fully restart Hearts of Iron IV and start a new campaign for a clean original EU setup. Existing adapted save games were not edited or migrated. The restored files were checked structurally and against the original; the running game's rendering was not tested.
