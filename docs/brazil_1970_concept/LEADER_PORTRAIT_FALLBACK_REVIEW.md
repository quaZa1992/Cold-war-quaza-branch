# Brazil 1970 unresolved portrait fallback

## Recommended fallback

Use `gfx/interface/coldwar_politburo/portrait_unknown.dds` for the 11 unresolved historical candidates listed in [leader_portraits.json](../../tools/brazil_1970_runtime/leader_portraits.json). It is already in the mod and measures 156 x 210 RGBA, matching the native HOI4 leader portrait canvas. Visual inspection shows a plain bust silhouette with the words “NO PHOTOGRAPH”; it does not depict a real or invented historical face. The requested portrait can refer to the path directly; avoid the existing `GFX_COLDWAR_SOV_pb_portrait_unknown` alias because its sprite name is tied to a different country feature.

This asset is registered in `interface/COLDWAR_SOV_1970_politburo.gfx`, whose comment says the graphics were generated by `cw_pbgui.py`. The original author and separate redistribution permission remain unknown. The project already documents that limitation in [the Argentina leader implementation note](../design/COLDWAR_ARG_1970/implementation_leaders.md). This recommendation reuses the file in place without copying or modifying it.

The base-game `gfx/leaders/leader_unknown.dds` is another 156 x 210 RGBA neutral silhouette, but lacks the explicit no-photograph label. Its base-game asset should likewise remain a path reference rather than being copied. The mod silhouette communicates the missing historical source more clearly.

For Luis Carlos Prestes, the installed Trial of Allegiance DLC has the correct exact-person portrait as `GFX_portrait_BRA_luis_carlos_prestes`. If the runtime selects it only when that DLC is enabled, the neutral silhouette is the no-copy fallback when the DLC is absent. All other unresolved candidates use the neutral silhouette until a correctly identified portrait has reuse rights verified.

## Art source revalidation

The current focus, idea, and event output files were rechecked against the live `interface/COLDWAR_BRA_1970.gfx` and declared native donor files. The full per-reference audit remains in [ART_IMPLEMENTATION_REVIEW.json](ART_IMPLEMENTATION_REVIEW.json): 224 focus icon references, 203 idea picture references, 22 event picture references, and zero missing or invalid aliases. All nine event assets remain 217 x 163 and byte-identical to their donors. The country event window and adjacent option grid remain unchanged from the Millennium Dawn donor.

No game code or portrait-helper implementation was changed by this review.
