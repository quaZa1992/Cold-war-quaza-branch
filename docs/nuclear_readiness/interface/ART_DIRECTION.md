# Strategic Command

The command panel uses a neutral missile, shield and radar emblem, deep green instrument wells, a restrained brass frame and phosphor-coloured readouts. Five numbered readiness instruments progress from subdued green to red. Readiness is communicated by the number, full posture name, selection frame and **IN FORCE** annunciator. A separate dashed amber frame and **PREPARING** label identify an outstanding order. Colour is never the only state indicator.

The 780 × 700 native window retains its existing screen footprint and the 56 × 26 topbar control. The four sections group national posture, arsenal and weekly expenditure, civil defence, and bilateral crisis communications. An active domestic or foreign ultimatum adds a dedicated warning plate. Alert fatigue changes from the normal readout colour to amber at 50 and red at 75. The tooltip retains the exact consequences. No readiness costs, timing, launch eligibility or diplomatic rules are changed by this visual revision.

All visible text remains English localisation, including both independently rendered lines of every posture name. Native fixed-size text boxes abbreviate embedded line breaks; each readiness label therefore has two explicit one-line widgets. The native political power icon and button disabled/hover states are retained. A panel-sized input surface prevents clicks through empty spaces to the map.

The original emblem was generated using the built-in ImageGen tool. The transparent master is [command_emblem_master.png](../../../tools/nuclear_readiness/art/command_emblem_master.png); the exact final prompt is [command_emblem_prompt.txt](../../../tools/nuclear_readiness/art/command_emblem_prompt.txt). Only alpha-bound cropping and proportional size export are applied. Runtime exports are `gfx/interface/COLDWAR_nuclear_readiness/logo.dds` (64 × 64) and `logo_small.dds` (24 × 24). The surrounding instrument graphics are generated directly by `tools/nuclear_readiness/command_ui.py`. Typography reuses the mod's existing Bahnschrift bitmap atlases under distinct readiness font names, preserving the original atlases and their other consumers.

`tools/nuclear_readiness/build.py` rebuilds the GUI, sprite registry, localised labels and runtime textures. `preview_command.py` verifies widget bounds and actual bitmap-font advances across six layouts: routine, preparation, strategic alert, an outgoing ultimatum, foreign release authority and long names/large stockpiles. It exports the proofs and a hashed asset manifest here. The offline proofs render the political power icon as `PP`; the game uses the native icon. Native rendering and interaction observations are recorded separately in `native_review.json`.
