### Design assessment and reusable choice shape

The current constitutional option (`gre_treaty`) already gives Greece a positive, native-mechanic result alongside reduced Cyprus officer penetration. The interference option (`gre_network` then `gre_coup`) has clear costs and a deterministic, high-risk outcome; it currently gives Greece no success reward of its own. At resolution, the coup succeeds only if penetration is strictly greater than `40 + preparedness`; a tie defends. For a Greece concept, make the pro-interference route attractive through a **Greece-side, temporary political or strategic payoff on an actual CYP success event**, while preserving the sunk PP/GDP costs, the warning window, the defence calculation, and Greek sovereignty limits. Keep failure consequential and do not deliver ownership, subject status or a free permanent alliance. A modest timed stability/foreign-policy benefit or political-power return can be considered after stacking it against existing Greek military spirits; treat the value as design work, not as a source-verified balance target. The current treaty's +5% foreign-influence defence and +2% stability are the local scale reference. Do not award army organization again by default: the shared `gre_officers` entry already adds +2% army organization permanently.

The most meaningful route split is therefore: honour the constitutional guarantee and reduce the network; or spend political capital to expand intervention leverage, accept domestic and diplomatic exposure, and gain a contingent Greek result only if the separate Cyprus coup check succeeds. The finite warning and the preparation choice are real costs, not flavour.

### Native European Community membership and a Greek accession path

The loaded MD system has no generic `EU_join` scripted effect. The native membership token is the country idea `EU_member`: its `on_add` registers the country in `global.EU_member` and runs `EU_init_default_europeanism` plus `EU_adopt_passed_laws`; its `on_remove` unregisters it and calls `leaving_EU` (`common/ideas/Organizations.txt:4-27`; `common/scripted_effects/99_eu_scripted_effects.txt:342-366`). Therefore a custom accession conclusion should add `EU_member` once, after all required recipient approvals, and should not set a parallel membership flag or manually maintain a second member list. `global.EU_member` is the live membership array and current-member loops already use `for_each_scope_loop` / `all_of_scopes` / `any_of_scopes` with `array = global.EU_member`; the membership idea hooks maintain array changes. This is a one-off completion-time iteration pattern, not a periodic scan.

The existing 1970 native setup helper `COLDWAR_EC_1970_initialize` seeds only the Six (BEL, FRA, GER, HOL, ITA, LUX) and the EC-era member array (`common/scripted_effects/COLDWAR_EC_1970_effects.txt:13-21, 26-50`). The Greece history file is itself an authored `1970.1.1` block and unconditionally includes `EU_member` in its `add_ideas` list (`history/countries/GRE - Greece.txt:1-2, 321-350`, especially line 339). I found no Greek or EC-startup removal; source therefore implies Greece is also marked as an EU member, even though the EC initializer adds only the Six. Check the live 1970 startup state and array synchronization before implementing an association premise; if Greece should begin frozen outside membership, remove `EU_member` at scenario initialization and verify that its `on_remove` cleanup is compatible with the startup array. When the concept restores association, model it as six distinct recipient country events to those actual founding states; only after the six approvals should the later accession focus send its application to the current `global.EU_member` array and collect those countries' event decisions. Resolve each recipient's assent/rejection into durable per-recipient receipts, then gate the final `add_ideas = EU_member` transaction on all required receipts. Do not hardcode the six founders as the final accession electorate, since membership may have changed by then.

This is a proposed use of verified native membership hooks, not an existing native political admission procedure. Source search did not find a general native `EU_join` effect or current-member unanimous accession ballot to call. The custom event-vote chain and exact consent threshold are concept work; only the actual membership idea/array behavior is native and verified. Existing EU focus/trigger code frequently reads `has_idea = EU_member` or iterates `global.EU_member`; the live member array is the right data source for a future/current-member consent stage.

## Performance and lifecycle constraints

There is one fixed-tag CYP monthly path and a USA fallback when CYP no longer exists. The monthly wiring calls the core update, clears expired pending offers, reconciles standing agreements, and reconciles crisis state (`common/scripted_effects/COLDWAR_CYP_R2_wiring.txt:13-18`; `common/on_actions/zzzzzz_COLDWAR_CYP_R2_on_actions.txt:5-18`). Relevant war relation, peace conference, annex, puppet and subject-free changes route directly to relationship reconciliation; this does not mean every tag is polled each day. Agreement sanctions and other unhooked diplomatic changes can wait for the next monthly fallback. Weekly money aggregation reads active stream flags and GDP values only (`COLDWAR_CYP_R2_wiring.txt:3-11`, `common/scripted_effects/COLDWAR_CYP_R2_crisis.txt:692-705`); keep foreign eligibility and relationship checks out of weekly arithmetic. The existing CYP monthly core also calls a helper named `COLDWAR_EASTMED_CYP_1970_daily_tick`, whose current body retires the modern roster and refreshes the old roster (`common/scripted_effects/COLDWAR_CYP_R2_core.txt:3456-3472`, `common/scripted_effects/COLDWAR_CYP_1970_regional_effects.txt:152-155`). This Greece concept should add no new daily/weekly crisis observer or relationship scan.

CYP-NATO eligibility is guarded by `COLDWAR_CYP_R2_nato_join_allowed` (`common/scripted_triggers/COLDWAR_CYP_R2_crisis.txt:153-165`). The Greece direct-entry action snapshots membership before leaving; the existing cleanup only returns each country that was a NATO member before this instance, after both GRE-TUR and CYP-TUR wars are over, and through native NATO join eligibility (`common/scripted_effects/COLDWAR_CYP_R2_crisis.txt:381-401, 645-730`). Do not wipe faction leadership or unrelated faction state; do not clear a still-active separation. The one early-reentry guard is an existing reusable helper, not a reason to clone NATO logic into a Greece domestic tree.
