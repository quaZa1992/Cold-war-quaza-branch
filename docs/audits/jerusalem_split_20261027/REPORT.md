Population allocation and historical scope

The existing project's calibrated total is preserved rather than replaced with a different census total. The approximate 74% west / 26% east allocation follows the 1967 sector distribution described by Maya Choshen in [Divided Cities in Transition II](https://www.ipcc-jerusalem.org/attachment/46/berlin%20map.pdf), section "Population Size in Jerusalem, 1967-2002". The [Jerusalem Institute's Facts and Trends 2021](https://jerusaleminstitute.org.il/wp-content/uploads/2021/05/Pub_564_facts_and_trends_2021_eng.pdf), geographical-distribution section, provides the institutional context and subsequent eastern population growth. This allocation is a map/balance approximation, not a claim that either assigned 1970 sector count is an exact historical census value. Both sectors retain the inherited Israeli ownership/control and Israeli/Palestinian cores; this review does not redesign the project's territorial-claim policy.

The initial failure was the module validator requiring a COMECON-specific first-line marker; the final generated headers retain both module and feature identification.
