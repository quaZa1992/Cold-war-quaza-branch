IMPERIA COLD WAR: USA 1970 expansion

This directory is the reproducible source for the approved 24 October 2026 USA expansion. The installed tree contains 301 focuses: the expanded 281-focus country tree plus 20 adapted generic naval focuses. Nineteen focuses originate recipient-approved international programmes, including the three early roots requested after screenshot review. The original approval covered 13 replacements and 52 additions; subsequent player revisions and the naval adaptation are separately recorded.

The 27 October capacity correction is documented in `docs/design/usa_capacity_20261027/IMPLEMENTATION.md`. Scripted instant grants of independent state buildings check their actual physical cap rather than a later manual-construction technology unlock. `usa_building_capacity.py` and the coordinator own the predicates and their single English requirement provider. `test_building_capacity.py` distinguishes those two kinds of capacity. Private native test data is stored on E:; the prepared A/B probe has not run while the user's game remains open.

The approved specification is `docs/design/usa_1970_expansion_20261024/proposal.json`. Its SHA 256 is pinned by `compile.py`; it is an approval record, not a generated output. `source_snapshot.json` preserves the exact authored pre-expansion USA source used for integration. Do not replace that snapshot with a subsequent generated tree.

## Regeneration

From the mod root:

```text
python tools/usa_1970_expansion/compile.py
python tools/usa_1970_expansion/validate.py
python tools/usa_1970_expansion/test_domestic.py
python tools/usa_1970_expansion/test_focus_dates.py
python tools/usa_1970_expansion/test_economy.py
python tools/usa_1970_expansion/test_early_cooperation.py
python tools/usa_1970_expansion/test_player_revision.py
python tools/usa_1970_expansion/render_installed.py
```

`compile.py` first regenerates the domestic, early-cooperation, advanced-agreement and economy modules, then integrates them into the frozen original tree and narrowly marked shared consumers. The agreement generator also runs its emitted-AST behavioral model. `--skip-content` rebuilds only the integration from the existing module specifications. A repeated full generation must leave gameplay output bytes unchanged.

`domestic.py` owns the six `COLDWAR_USA_1970_programmes` runtime files and its integration specification. `agreements.py` owns the seven `COLDWAR_USA_1970_agreements` runtime files and its specification. `early_cooperation.py` owns the seven early-cooperation runtime files and root/follow-up specifications. `economy.py` owns the narrow tax initialization and once-only save migration. `focus_dates.py` supplies pure availability transformations, preserving actual election chronology. `compile.py` owns the main tree, lifecycle bridge, legacy previews, enactment recovery and targeted original USA integrations. `focus_titles.json` supplies short map captions; full descriptions, agreement names and spirit names remain separate.

The existing Gulf programme remains generated by `tools/iraq_1970/usa_module.py`. Its weekly-to-daily fixed-point repair is documented separately. Do not run the full Iraq generator as part of an ordinary USA rebuild.

## Validation scope

`validate.py` checks the installed graph, exact approved placement, exclusions, branch visibility, exact party gates, construction guards/slots, encodings, helper providers, money consumers, old event retirement, native research/modifier providers and all 281 caption widths. It parses the targeted USA runtime files. External helper names are indexed without attempting to audit other concurrent country work.

`usa_building_capacity.py` derives the shared-slot, independent-state or province building class from current MD definitions. All three compilers use it; the coordinator generates current capacity predicates rather than copying historical audit suggestions. The `include_locked` option is emitted only for actual shared-slot buildings. `CAPACITY_FIX.json` in the implementation report directory documents the live screenshot regression and its current verification limits.

`test_domestic.py` executes a bounded model of the emitted domestic transactions. Agreement model cases execute the generated agreement AST. These are source/model checks, not claims of live multiplayer or native tooltip testing.

`render_installed.py` reconstructs the current tree using the registered MD artwork, title bars and bitmap font. The views are generated from installed sources; they are not game screenshots and their orthogonal connector routing approximates the engine.

`native_probe.py --plan` reports the isolated native fixture. Prepare a task-owned frozen snapshot and a separate copied asset provider before launching. The launch requires the exact returned freeze SHA 256, refuses an existing game in its process context, uses a separate profile and terminates only the process it created. Never reuse the shared multiplayer-quality profile. Native checkpoints, full diagnostics and unperformed checks are recorded separately in its run result. Fixture-only Canadian and British AI event weights select Review so a spontaneous AI answer cannot race the pending-state assertions. Their production transaction helpers are then called explicitly. A direct scripted acceptance in this fixture is not a human recipient click, an AI-choice test or a network test. Actual game AI weights remain unchanged.

The completed 24 October run passed 92 native checks before the screenshot revisions. It does not cover the current independent-building capacity, focus-date, early-cooperation or tax changes. The future fixture now establishes the real Canadian parent and verifies the new-start tax receipt; that revised fixture has not been launched. Its reports, full logs, exact fixture/loader sources, hashes and earlier attempts are retained under `native_probe/runs/usa_final_20261024`. Its bulk provider, runtime copy and profile were removed after evidence retention. Prepare a fresh run before another launch; the archived paths in its immutable freeze manifest identify the original test locations. `EVIDENCE_RETENTION.json`, `CLEANUP.json` and the compressed asset manifest record this cleanup.
