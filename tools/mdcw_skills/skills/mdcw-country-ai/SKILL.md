# IMPERIA COLD WAR — Country AI paths and RP boundaries

Read `AGENTS.md` and [references/ai-paths.md](references/ai-paths.md). Resolve the real 1970 tag, tree, existing game rule, startup wiring, path flags, AI strategy plans, party model and country mechanics. Research the intended historical government and later transitions rather than importing a modern MD timeline.

Inventory the full prerequisite and availability graph, event-driven forks, multiplicative weights, starting burdens and every relief route. Use an AI path report only if it actually exists and its coverage fits this checkout. Inspect uncertain branches and external readers directly; a tool report does not decide every mechanical question.

Preserve the campaign's existing game-rule defaults and option semantics unless redesign is authorized. If adding options, make each coherent and reachable. Ensure a random selection's chosen state reaches all relevant readers, while an unrestricted option retains functional baseline AI. Do not blindly convert every country flag to a global flag or remove a rule merely because a filename heuristic misses the tree.

Keep every AI-controlled country able to address its actual starting penalties. Trace exact ruling-party gates, popularity/elections, crisis decisions and programme cleanup. Use established party and leadership effects; do not overwrite a human government or impose a date-driven walker on an undated successor roster.

Provide AI access through current supported GUI AI behavior or decision/effect paths as appropriate. Verify the actual engine and project implementation instead of asserting that every scripted GUI is inherently AI-unusable. Equivalent outcomes must retain real payment, prerequisites and consent. Human recipients and GC-only actions remain under their real authority.

Verify spending bankruptcy guards in AI weights separately from genuine human affordability checks. Check each path against historical AI on/off, event choices, excluded branches, government transitions and available cures. Do not ban all strategy edits or require a PR, particular prose length, comment deletion or new-country quota because upstream did.

Patch generators as well as runtime output. Report graph and model evidence separately from actual AI playthroughs, with unresolved long-run behavior stated plainly.
