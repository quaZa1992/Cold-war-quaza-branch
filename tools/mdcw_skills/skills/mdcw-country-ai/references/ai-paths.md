# IMPERIA COLD WAR — AI-path verification matrix

For each selected rule state and historical-AI setting, trace the actual startup selection, path receipt, event choice, strategy plan, focus weighting, party transition and crisis cure. No-path behavior, random selection and historical defaults are design choices to preserve unless the user changes them, not universal modern-MD requirements.

Multiple prerequisite blocks mean AND; multiple focuses in one block mean OR. A multiplicative zero can make a later additive or plan preference ineffective. Inspect complete weighting, not just a positive path modifier. A shared focus tree must not inherit one country's path killswitch across all members.

For each starting burden, find actual readers and every relief path. Check sign, caps, active party, event gates, bankruptcy, missions and parent membership. Do not assume every spirit is a penalty or that an unresolved cure in a partial input is a confirmed defect. Equivalent AI routes retain real costs and eligibility.

Historical leadership needs a real dated office-holder timeline. An undated roster can contain opposition figures or plausible successors. Reuse the project's existing election, succession and party effects. Inspect arrays and all index consumers before changing a roster. Restrict AI automation to AI countries and preserve human RP choice.

GUI AI capability depends on current native support and the actual GUI configuration. Upstream documents disagree between a blanket AI limitation and supported `ai_enabled`/`ai_weights` patterns. Resolve the actual mechanism locally. Prefer an existing equivalent decision/effect path when appropriate; do not add a second free daily repair loop just to make a graph report green.

Review 1970 OOB, equipment variants, research and production technology when path choices depend on military capacity. A modern equipment role, NATO assumption or 2000 history block is not proof that a 1970 country can build it. Treat report heuristics as evidence to inspect, never a mandate to delete content or retune history.
