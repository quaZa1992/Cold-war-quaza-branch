# IMPERIA COLD WAR — Development diaries

For a format conversion, preserve the author's prose and image order except for requested edits and the project's punctuation rules. For a newly authored diary, explain the actual 1970 country, institution or mechanic in concise English and distinguish implemented features, concepts, previews and planned work. Do not silently translate supplied prose unless requested.

Read the source document's text and media relationships. Keep each screenshot next to the passage it illustrates and preserve credits. Use the real developer credit, client date and project version when known. Ask only for genuinely required metadata that cannot be resolved. Avoid claiming an engine screenshot when an image is a composed preview. Keep debug internals, unverified MP claims and proposed features out of descriptions of released behavior.

Begin new project documentation with IMPERIA COLD WAR, after mandatory frontmatter if the format requires it. Preserve existing document attribution and record new media sources and permissions. Do not add game localisation or alter game scripts as part of formatting a diary.

Verify links, image formats, captions and the destination's actual build checks. A local diary draft does not authorize publication, a release, a PR or messages to other people. Report the artifact and any metadata or visual checks still needed.
