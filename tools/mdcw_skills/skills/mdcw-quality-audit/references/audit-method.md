# IMPERIA COLD WAR — Evidence-driven mechanic auditing

Use the requested scope. For a branch, inspect the relevant commit range plus working-tree changes; for a named installed mechanic, inspect its live entry points even on a clean main branch. Keep binary inspection and generated-output closure where the mechanic needs them. Do not overwrite immutable approvals or another chat's WIP with a broad rebuild.

Review correctness and native support, 1970 reachability, player presentation, periodic work, AI access, RP authority and persistent lifecycle. Trace providers through consumers. A modifier definition is not proof that an active formula reads it; a matching tooltip is not proof that the engine executes it. Native documentation, current MD implementation and bounded observations have different evidential roles.

The audit roles in upstream `.claude/agents` become review perspectives, not mandatory agents or model selections. Work directly unless the user or applicable instructions authorize delegation. Correctness, edge cases, content, performance, simplification and Python generator/tooling concerns should contribute only findings justified by the change.

For generator tooling inspect output-root controls, staged versus installed parity, fixture cleanup, subprocess arguments, encoding and protected input hashes. A validator must not manufacture its own expected behavior or replace a historical baseline merely to pass. Source scans, model tests, operation counts and isolated native probes must be labelled accurately.

Current local examples include `tools/multiplayer_quality`, `tools/space_race_1970`, `tools/nuclear_intelligence`, `tools/quaza_nuclear_integration`, `tools/colonial_affairs`, `tools/diplomacy_1970`, `tools/gc_unsc` and country-specific suites. Discover and inspect their present state rather than treating this list as a fixed test plan. The historical broad audit runner writes dated artifacts and has no universal modern MD validator interface.

UN work must preserve the project's current RP/GC appointment model. Do not replace session-based seats or local consent rules with modern upstream's automatic election recipe merely because its reference is more recent. Likewise, uranium deposits unlock paid development and do not imply starting raw production or built mines.

Report each material finding with severity, exact source line, trigger, impact, smallest correction and evidence. State unresolved native behavior precisely. A real MP claim requires the relevant multiple-client, co-op, simultaneous action, rehost, save and calendar tests; a one-hour single-client load probe does not provide them.
