# IMPERIA COLD WAR — Available checks and honest evidence

Discover the present tooling before choosing commands. The adaptation checkout had no modern `tools/validation`, `tools/analysis`, `tools/standardization` or `tools/run.py`. Existing domain checks live in `tools/<feature>/test_*.py`, `validate.py`, country-specific validators and Space Race `qa_*.py`. Reconfirm paths and inspect inputs, flags and mutations.

`tools/multiplayer_quality/audit.py` exposes parser and scan helpers, but its CLI dispatches a fixed option dictionary and its default output is a dated audit folder. It is not a harmless `--help` command or a standard universal validator. `native_probe.py` can create snapshots and launch an isolated hidden game profile; inspect its source and provide a fresh supported audit output. It is not a multi-client test.

Prefer the owning generator's staged output and relevant tests for changes to generated content. Record whether a test reads live files, fixtures, cached snapshots or a simulation. Check fixture rollback behavior and do not execute a suite that silently rewrites shared live content during another chat's work.

For complete warning reports, use actual full sidecars or captured output. Some upstream tools cap the console at 50 findings, but verify the current implementation before assuming that cap or schema. Preserve every finding and its original category/severity/order in the complete artifact. Add project identification without invalidating a strict runtime schema; a companion notice is appropriate when metadata cannot be added.

Classify orphan/reference findings by the complete provider universe. GUI calls, scripted dynamic dispatch, inherited sprites, file-local constants, later scenario blocks and intentionally reserved event IDs can defeat naive text scans. The source itself, current native docs and a reproduction resolve the finding; a false-positive list is not automatic immunity.

Keep immutable historical baselines unchanged. When later approved changes make whole-file preservation assertions obsolete, explain the old contract and verify current invariants separately. Do not count a retired test as passing or relabel every failure as stale. A current target failing its actual functional contract remains a defect.

Evidence levels: source structure/reference/encoding checks, behavioral model tests, static operation estimates, native startup, native UI, native calendar/save/reload and live multiplayer. Name exactly which levels ran and what remains. Existing reports guide the next check but do not prove today's source passed it.
