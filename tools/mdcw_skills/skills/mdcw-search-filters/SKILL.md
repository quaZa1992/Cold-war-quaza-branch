# IMPERIA COLD WAR — Focus search filters

Read `AGENTS.md`. Resolve the named tree or changed focus files and their source generator. Parse focus blocks; do not infer ownership or effects from ID substrings alone.

Find the current supported generic and country-specific filter keys, their English display keys and native usage in the checkout. The upstream list is a starting point, not authority for every custom Cold War registration. Distinguish a verified unregistered filter from one defined outside a partial fixture.

Check missing filters, typos and obsolete aliases, cross-country custom keys, and a missing useful generic filter beside a country-specific tag. Select filters by the actual branch/effect. Political, industry, foreign policy, military laws, service and research categories should remain useful to a player; avoid tagging every conceivable secondary effect.

For a spending filter, trace the actual treasury cost, including payments hidden inside building helpers. Completion time is not monetary expenditure. Check the current bankruptcy mission guard in AI weights. This AI safety guard does not replace legitimate human affordability checks or runtime transaction validation. Do not remove those checks by applying upstream's wording that a bankruptcy guard belongs only in `ai_will_do`.

Keep preview-only setup separate from execution. Do not add unsupported filters, change focus rewards, rewrite political gates or impose a fixed payment threshold on all countries. Preserve the existing tree's logical graph and native visibility standards.

Report the focus ID, current filters, concrete issue and recommended registration or replacement. When fixes are requested, update canonical and emitted sources, then verify the actual set of focus/filter references. State when no issues were found in the reviewed scope.
