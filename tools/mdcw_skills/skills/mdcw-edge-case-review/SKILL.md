# IMPERIA COLD WAR — Edge-case review

Read `AGENTS.md` and [references/scenarios.md](references/scenarios.md). Resolve the actual requested file, diff, mechanic or fixture. Include relevant working-tree changes when reviewing uncommitted work. A clean diff against `origin/main` does not mean a named mechanic has nothing to review. Do not fetch, switch branches or modify files merely to obtain a review baseline.

Trace entry points, delayed events, native scopes, persistent state, cleanup, previews and the canonical generator. Include generated runtime output and relevant asset closure. Inspect external consumers before calling a rename or deletion safe. Partial fixtures leave missing providers unresolved rather than automatically broken.

Challenge the behavior under two humans acting at once, co-op, duplicate clicks, refusal, expiry of an offer, insufficient funds, target annexation, civil war, controller changes, war, sanctions, government changes, save/load and rehost. Separate deliberately reserved RP/GC authority from a missing guard. An AI fallback must not accept a human player's agreement.

Check actual transaction boundaries: final eligibility and money checks belong inside execution, followed by one-time receipts. A visible or enabled button does not authorize an otherwise invalid effect. Verify every `ROOT`, `FROM`, `PREV`, stored country scope, array index and denominator at its actual call site.

Report only actionable findings with severity, current absolute path and line, reproducible trigger, consequence and smallest safe correction. Separate confirmed defects from native questions and historical warnings. Respect a request to ignore earlier crashes; do not reopen them without current evidence relevant to the assignment.

Review requests do not authorize implementation by themselves. When fixes are already requested, implement and verify the supported fixes without turning the review into a balance redesign. Do not auto-create agents, PRs or issue comments.
