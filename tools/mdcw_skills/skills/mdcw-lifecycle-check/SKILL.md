# IMPERIA COLD WAR — Country integration readiness

Read `AGENTS.md`. Resolve the requested country and actual native tag. Discover its active files through tree selectors, history, references and generators rather than assuming `05_TAG.txt`. Use a supplied fixture as the target when requested.

Inventory the applicable integration surfaces:

- January 1970 identity, ruling party, leader, laws, economy, territory, OOB and available equipment.
- Focus selectors and graph, real rewards, ideas, programme activation/cleanup and reachable mechanics.
- Decisions, event chains, bilateral delivery, consent, sanctions, suspension and restoration.
- Exact party localisation hooks, focus/idea/decision/event text and native numeric previews.
- Focus and spirit artwork, portraits, native event framing, GUI neighbours and asset provenance.
- Unit names, research categories, AI/game rules and access to necessary cures.
- Generator parity, immutable approvals, targeted checks, existing release notes and any requested publication.

For each applicable item mark verified, partial, missing, not applicable or unverified, with the actual source/evidence. File existence and reward-block counts alone do not establish completion. Do not require a navy, new custom mechanic, separate file or extra events where the design does not call for them.

Check that content is reachable from the real 1970 setup, with later historical identities gated correctly and other scenarios preserved. Keep party branches inspectable and member-only entries dependent on actual membership. Trace every bilateral target to the real registered country.

Separate source completeness, model tests, native load, native UI, native save/reload and live network rehearsal. Reading an old report does not execute its checks today. A clean startup log is not a playthrough and an empty console is not OOS evidence.

Respect existing design authorization. Do not infer an unfulfilled draft-approval requirement solely from upstream's process. Report material missing pieces and the smallest next checks without auto-implementing an unrelated country overhaul.
