IMPERIA COLD WAR: GC session-based UN Security Council seats

The human Game Controller can activate five elected seats in the existing GM Decisions category. Open `Show UN Security Council Tools`, then use `UNSC: Enable Session Appointments`. This replaces the ten existing elected mandates with five vacant RP seats. It preserves the actual permanent-member roster and all permanent-member ideas, modifiers and vetoes. Activation is explicit and campaign-wide; there is no automatic activation or dated country assignment.

To appoint a country, open one of its owned states and use the existing GC target button (`Set State & Country as GM Target`). The category header already shows that selected country. Use the assignment decision for Europe, Americas, Africa, Middle East or Asia. Each decision shows the current member and selected country. Reusing the decision with a different target replaces only that seat. Five separate `Vacate` decisions can clear occupied seats. All actions cost 0 PP and take effect immediately. The expand/collapse descriptions show the five-seat register.

The GC determines geographic eligibility under the RP session's wheel rules. Native MD's power-ranking regions are deliberately not imposed: their Middle East pool includes countries that an RP group may allocate to Africa, and regional classifications can diverge from session rules. Human and AI countries can be selected. The target must exist, belong to the actual UN General Assembly, be recognised, not have capitulated and hold no elected or permanent Council seat. No country or player from the supplied example is fixed in runtime code.

Assignments persist in global country variables across session breaks and save/load. There is no game-date expiry. Council changes wait until both the current Security Council vote and any elected-seat General Assembly election have ended. Other General Assembly votes continue normally. Runtime effects repeat the authority, target and vote checks, including when a previously displayed decision is stale.

The authoritative native voter array is rebuilt from the occupied seats and the current permanent-member array. Empty seats have no zero placeholder. Native voting thresholds retain MD's existing 60% rule and exclude the resolution's subject. Veto checks remain native. The Council GUI already renders this array, so it displays the new elected members without a second simulated membership idea or a replacement UI.

Calendar nomination, January rotation, election-result callbacks and new type-6 elected-seat proposals are suspended in RP mode. Activation clears pending election cohorts and removes only type-6 entries from the parallel GA queues. Other queued proposals retain their order and country association. Membership loss or annexation vacates the affected seat. Permanent promotion vacates its former elected seat and adds the country to the actual permanent roster. Neither path randomly appoints a replacement in RP mode. When RP mode has not been activated, native calendar behavior remains available.

Integration is limited to `common/scripted_effects/01_international_systems_effects.txt` and the `p5_member` lifecycle hooks in `common/ideas/Organizations.txt`. Custom decisions, effects, triggers, dynamic text and English localisation are in the corresponding `COLDWAR_gc_unsc` files. There are no new recurring scans, on-actions, assets, historical national policies or national spirits.

Validation: `python tools/gc_unsc/test_session_seats.py` executes the emitted decisions, parameterised effects, native voter threshold, native annual rotation and native permanent/member-removal transactions. The interpreter rejects unknown statements and out-of-range array reads. UI invalidation and unrelated subsidy providers are recorded as external API calls. The suite also checks localisation keys, punctuation and BOM rules. `python tools/diplomacy_1970/test_diplomacy.py` covers the existing historical roster and German diplomacy integration.

Native engine verification is still required: in a multiplayer test save, activate the mode as the human GC, assign five different countries, verify the Council flags and vote eligibility from a recipient, replace and vacate a seat between votes, cross June and January, then save/reload and verify the same register. Source tests do not emulate native rendering, serialized saves, event delivery or multiplayer synchronization.
