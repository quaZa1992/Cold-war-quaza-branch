## Mechanics checked

- **1970 loading and scope:** all 14 country-history files now load `COLDWAR_SSR_1970_focus`; Ukraine is an example at `history/countries/UKR - Ukraine.txt:55`. The 1970 startup initializer also visits the 14 tags in `common/on_actions/COLDWAR_SSR_lifecycle_on_actions.txt:4–18`. The fallback tree loader keeps completed focuses when attaching the tree (`common/scripted_effects/COLDWAR_SSR_focus_rewards.txt:2–7`).
- **Status lifecycle:** ordinary SSR content uses `COLDWAR_SSR_is_ssr`, which requires the recognized 1970 participant identity and Soviet-subject status, while post-sovereignty content uses `COLDWAR_SSR_is_independent`, which requires a recorded transition, no current subject status, and no capitulation (`common/scripted_triggers/COLDWAR_SSR_lifecycle_triggers.txt:5–9`). In the emitted common tree, the Republican Administration entry has the SSR status gate at `COLDWAR_SSR_1970_focus.txt:27–31`; the independent public-authority root has the independence gate. No communist-party or Soviet-outlook condition is used as a substitute for the shared SSR status gate.
- **Party modules:** focus availability uses the registered MD party-in-power triggers, and the reward helpers repeat them alongside the status, receipt, country, prerequisite, and exclusion checks. `allow_branch` remains country-scoped, so party modules remain visible when another party governs. For example, Ukraine's public and market ownership choices require `emerging_communist_state_are_in_power` at `COLDWAR_SSR_1970_focus.txt:3753–3758`; MD defines that trigger against `ruling_party = 4` and the native Communist State localization in `common/scripted_triggers/01_political_triggers.txt:197–202`.
- **One-time effects and assets:** focus completion calls a guarded reward effect; the helper rechecks availability, receipt, prerequisite receipts and exclusions before charging GDP, adding assets, and writing the receipt (`compile.py:112–123,170–180`). Building availability and execution both require an owned, controlled core state with native free capacity; coastal and resource requirements are checked separately (`compile.py:74–90,99–110`). The emitted construction sequence adds one shared slot before the building level, including infrastructure and power plants (example at `COLDWAR_SSR_1970_focus.txt:736–737`). No duplicate construction path was found in the reviewed focus helpers.
- **Research and doctrine:** emitted research rewards use existing MD categories such as `CAT_industry`, `CAT_electronics`, `CAT_infantry`, `CAT_artillery`, `CAT_tanks`, `CAT_aircraft`, and `CAT_corvettes`; these categories have provider technologies in `common/technologies`. The three land-doctrine rewards use the native `add_doctrine_cost_reduction` form with one use and `land_doctrine` (for example `COLDWAR_SSR_1970_focus.txt:1981, 3106, 3139`), matching existing MD focus usage.
- **Union Plan placement:** the donor root remains at `(355, 8)`. Its generic-host offset remains `(-115, -8)`, resolving to `(240, 0)`; the SSR host offset is `(-285, -8)`, resolving to `(70, 0)`. The SOV host has no added offset, so it retains `(355, 8)`. The emitted joint focus keeps both host-specific offsets in `COLDWAR_UNI_1970_union_joint.txt:14–27`, and `cw_union.py:1183–1188` preserves them when the SOV generator runs.
- **Intentional country restriction:** the navy works focus checks for an owned, controlled core coastal state with dockyard capacity (`COLDWAR_SSR_1970_focus.txt:9285–9299`). Landlocked republics therefore cannot take that asset focus; the coast requirement is explicit and separate from the SSR status gate.
