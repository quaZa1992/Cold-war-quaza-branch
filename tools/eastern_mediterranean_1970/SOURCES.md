# Selected historical portrait sources

All named portraits were restored with built-in imagegen from the referenced historical photographs. The requested base prompt is: Kolorisiere es und mache das wie ein handyfoto. Source-specific backgrounds are retained or adapted to the original setting; there is no common studio-background rule.

The authoritative selected masters, complete prompts, revision prompts, source URLs and any date qualifications are in generation.json and generated/*.json. Unselected intermediate images are not game assets. Captures are not all from1970: period-adjacent sources and undated official portraits are explicitly qualified below.
