# Native UAE reward presentation

`presentation.py` returns snippets for the compiler's existing non-executing `effect_tooltip`. It neither imports the compiler nor writes generated content. Real grants, prices, caps, focus positions and consent remain owned by the existing implementation.

The API is `native_tooltip_key(modifier, data, loc)`, `native_tooltip_keys()`, `spirit_change_preview(node, data, loc)`, `programme_preview(node, data, loc)`, `maritime_oil_preview(node, data, loc)` and `special_preview(node, data, loc)`. Only missing formatter/status localisation is registered in the supplied dictionary.

The native references are main MD `05_russia.txt:410–413` (named dynamic modifier plus numeric variable-effect formatters), `:34232–34251` (native construction/resource/treasury effects), `MD_dm_modifiers_l_english.yml` (native names, colours and numeric units), and `05_united_kingdom.txt:20914–20917` (temporary arithmetic inside `effect_tooltip`). The base-game modifier formatters are also used. The current native formatter inventory contains831 keys.

The110 focus previews require two custom modifier formatters: Imperia sanction resistance and additional incoming investment slots. The broader approved modifier-label inventory also contains an unused oil-price-resistance formatter; the validation report distinguishes inventory fallbacks from actually emitted fallbacks. These fallbacks reuse registered modifier names and their existing percent/integer units.

Starting-spirit previews reconstruct current and post-focus values from earned flags using the actual strongest-per-family credits, summed families, cabinet/mediation remedies and zero clamps. They display the resulting marginal modifier changes beneath the native named modifier heading. A fully removed starting spirit also receives a native removal preview, gated on its current presence. An already removed penalty is not presented as a second full bonus.

Political stability previews display the actual additional contribution after the positive15-percentage-point cap. Negative contributions remain separate. Advertised main-programme numbers are unconditional preview rows; actual activation conditions remain in the live reconciler. Future agreement rewards use native `TT_IF_THEY_ACCEPT`. Conditional arithmetic for caps, spirit relief and dated office appointments retains its native branches. Duration is shown only for timed contributions. The planning join has one essential continuation line; actual proclamation uses native name restoration, the qualifying dated dynasty's actual native leader appointment and cabinet status. Alternative parties receive no promised dynastic appointment. The date comparisons exactly match the current provider, including succession from2022-05-13.

Dirham establishment previews the actual currency-law idea. British protection, early handover and friendship preview native recipient events under the same dispatch conditions. None of these previews executes an event, payment or appointment in the live game.

`test_presentation.py` compares emitted spirit and cap calculations with the actual compiler's programme reconciler across earned stages and remedies, exercises the cap at its boundary without changing approved data, and compares proclamation appointments/offices with the actual political provider across72 date/party/cabinet combinations. Current counts are recorded in `PRESENTATION_VALIDATION.json`. These are AST and source comparisons; native hover rendering remains unobserved.

Population-growth focus previews now show the actual marginal contribution below, at and across the total+200% tree cap. The compatible routes supply+160% or+200%; even all five population-focus receipts cannot exceed+200%. Prices, other rewards and drawbacks remain unchanged.
