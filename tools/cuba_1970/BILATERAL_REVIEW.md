# Cuba bilateral agreement review

Independent static review of the generated bilateral runtime files. The review covers paired spirits, recipient consent, refusal/expiry receipts, cancellation, legacy adoption, native effect previews, localisation and script references.

The current emitted outputs pass Clausewitz AST parsing for all six script files and the independent static checker in [validate_bilateral.py](validate_bilateral.py) (296 checks). The project validator passes 5,201 checks, with all 120 approved focuses emitted at unique positions. Each script starts with the exact `# IMPERIA COLD WAR — <feature>` marker and is UTF-8 without BOM; the English localisation retains its UTF-8 BOM. The checker confirms eight term pairs across SOV, MEX, Spain and Canada; paired idea definitions and English keys; local idea sprite registrations; proposal and response decisions; native effect previews separated from hidden mutations; persistent first-payment receipts; cancellation reconciliation; and bilateral peace, embargo and all four Imperia sanction arrays in both directions.

The medical legacy path removes the old timed idea before reconciliation, so an explicit termination cannot be immediately re-adopted. Legacy SOV and DDR terms migrate only when both countries carry the corresponding active receipt, then use the shared bilateral peace and sanctions checks. The medical recipient trigger restores the recipient scope from Cuba with `PREV`.

The first generated draft had unmatched braces in partner cancellation and refusal decisions. Those were corrected before this review was closed; all emitted script files now parse. The latest emitted idea portraits use `communism3` and `generic_healthcare`, which both resolve through local idea sprite registrations.

The final native-engine probe completed in 290.8 seconds with 107 expected cases: 105 executed and passed, two explicitly skipped, zero failed, and zero Cuba-specific engine errors. The skipped cases were the two native embargo suspension/restoration tests because By Blood Alone was unavailable in the test profile. The executed coverage includes all eight bilateral terms through wrong-term blocking, signing, first payment, replay prevention, either-side cancellation and re-entry without a second fee; all 16 sanction-array directions across four sanction types and both countries; war/peace suspension; medical consent, recipient-scope checks, restoration and cancellation without legacy resurrection; interests-section acceptance and cancellation; and legacy Soviet suspension/counterparty cancellation. The fixture also reports the existing-save island investment repair passing.

The probe binds ROOT-sensitive response decisions to a fixed recipient and uses real DDR, Soviet and USA offer helpers for initial pending proposals. It does not verify multiplayer behavior, manual decision UI/hover rendering, ROOT-sensitive external sanction hooks, or offers after 1972. The two embargo cases remain untested because of the missing DLC; they are not counted as passes.
