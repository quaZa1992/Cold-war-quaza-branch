# Original MD reference checker

The CWEC game implementation was retired on 18 October 2026. Its generators and validators were archived with the rollback backup so they cannot inadvertently reinstall the removed system.

`python tools/europe_1970/check_original_md_reference.py` only checks the reviewed original Workshop files. It does not change the Workshop or the active game scripts.

All custom EU adaptations, including the subsequent native-interface adaptation, have now been removed. The current restoration record is `docs/main_md_eu_restore/README.md`. Only the read-only original-reference checker remains here; the adaptation's generators and validators were archived and removed.
