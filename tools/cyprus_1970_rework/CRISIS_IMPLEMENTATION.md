# IMPERIA COLD WAR — Cyprus crisis generator implementation note

This note covers the generator module in `crisis.py`. It does not claim that generated runtime files have been installed or tested in a live game.

## Generated interface

`build(design)` emits six UTF-8 script files, English localisation, and integration metadata. It provides the 16 actor focus `_available`, `_apply`, and `_preview` effects; the three Turkish army-crisis events and four finite Turkish crisis actions; guarantor and Geneva response events; cached weekly expense calculation; monthly reconciliation; and NATO return guards. Country events use the agreement module's `GFX_COLDWAR_CYP_R2_agreement` sprite. Actor previews are unconditional native `effect_tooltip` blocks and do not call availability or transaction effects. Spirit descriptions carry their signed modifier values.

The compiler must call `COLDWAR_CYP_R2_crisis_monthly = yes` once from CYP scope on an existing monthly fixed-tag hook, call `COLDWAR_CYP_R2_crisis_reconcile = yes` from CYP scope on war and settlement transitions, and add `COLDWAR_CYP_R2_crisis_weekly_streams = yes` once per country to the native weekly expense aggregation. If Cyprus no longer exists, the parent-owned USA monthly fallback can call `crisis_reconcile` from USA scope; that helper uses fixed GRE/TUR scopes and treats the missing CYP-TUR war pair as ended. The returned cached total is in weekly GDP units. Weekly stream evaluation reads flags only; it does not scan wars, diplomacy, ideas, or volunteers.

The shared NATO integration remains parent-owned. Add `COLDWAR_CYP_R2_nato_join_allowed = yes` to the real `NATO_join` and `NATO_join_via_event` admission checks and the accession acceptance path. The module's return effect only retries for countries that held NATO membership before this intervention. It requires both Cyprus-Turkey and Greece-Turkey peace, a living NATO leader, independence, no incompatible faction, and no war with current NATO members. It delegates all array, access, opinion, technology-sharing, and faction changes to native `NATO_leave` and `NATO_join`.

The four army-crisis actions are one-shot. The crisis starts at pressure 70, the day-30 memorandum adds 15, and both once-only control measures subtract 25. At day 60, pressure 60 or more installs Turkey's dated slot-22 leader through `COLDWAR_TUR_1970_set_leader`; pressure 36-59 defeats the plot with stability -5%; pressure 35 or less defeats it without that penalty. Paid focus and decision completion refreshes the relevant GDP percentage immediately before its final affordability check; weekly stream values remain cached. Control and intervention close the army instance before proceeding. Delayed events require the still-active instance, so stale outcomes do nothing.

## Source checks and limits

- Native NATO membership effects are in `common/scripted_effects/01_NATO_effects.txt`: `NATO_join`, `NATO_join_via_event`, and `NATO_leave`. The current faction checks are in `common/scripted_triggers/00_NATO_scripted_triggers.txt`; `NATO_currently_exists` only checks that the member array is nonempty, so the return trigger also checks for an extant member that is faction leader.
- Native volunteer recall is `recall_volunteers_from = PREV` in `common/scripted_diplomatic_actions/00_scripted_diplomatic_actions.txt` (the recall action's completion effect). Monthly reconciliation uses `recall_volunteers_from = CYP` when the Greek mission becomes ineligible. Expense accrues only when the monthly cache observes actual Greek volunteers in Cyprus.
- Native game precedents support the volunteer idea's `rule = { can_send_volunteers = yes }` and its targeted `add_relation_rule_override` / `remove_relation_rule_override` lifecycle for Cyprus. These authorize native diplomacy without creating substitute units. Greece and Turkey remain NATO members during the volunteer branch; actual division deployment against an ally still needs a manual native-diplomacy check.
- `common/scripted_effects/00_money_system.txt` owns weekly expense aggregation and treasury settlement. This module returns `0.00005` Turkish GDP per week during intervention and `0.00002` Greek GDP per week only while deployed volunteers are cached as active; the literals stay within the five-decimal rule.
- `COLDWAR_CYP_R2_crisis_monthly` is the only periodic reconciliation. War-start, peace, and accepted-settlement changes should use the targeted transition hook so the monthly fallback is not the primary response path.

The compact checks in `test_crisis.py` validate output markers, helper coverage, non-executing previews, crisis gating and math, separate mediation response/deadline events, four native-effect army actions, NATO leader/peace guards, and the cached-only weekly stream. They do not validate Paradox parser acceptance, event arrival, same-faction volunteer behavior, war-side formation, NATO membership transitions, or multiplayer performance in a running game.
