# Country naval adaptations

`profiles/*.json` owns country names, institutional prose, integration parents, coordinates and actual construction targets. `naval_adapter.py` derives the native generic naval chapter and emits only marked country-tree additions and the five shared runtime providers. It does not regenerate an unrelated country programme.

Run `python tools/naval_adaptation_1970/naval_adapter.py` from the mod root. The writer preserves all content outside its marked block. Native generic changes fail the expected 20-focus closure until reviewed. Country-owned canonical emitters also call the pure integration function and include the same runtime pack, so a later country build retains the chapter.

Run `python tools/naval_adaptation_1970/verify_build.py` for the source/model checks and scoped rebuild comparison. This executes the authorised USA coordinator, the bounded five-country writer and tests. It never executes broad Soviet, DDR, Iraqi or Emirati builds. `test_owner_hooks.py` isolates the pure Soviet/DDR focus emitters with ordinary writes blocked and checks the IRQ/UAE hook paths without invoking their broad builders.

Run `python tools/naval_adaptation_1970/render_installed.py` for native-asset source previews. They use actual installed coordinates, registered icons, titlebars and bitmap glyphs. Connector routing is approximate, and these images are not live game screenshots.

Design, historical sources, balance details, evidence boundaries and provenance: `docs/design/naval_adaptation_1970_20261025/IMPLEMENTATION.md`. The original generic MD file and art remain unchanged. Existing licence and upstream attribution remain separate from the project marker.
