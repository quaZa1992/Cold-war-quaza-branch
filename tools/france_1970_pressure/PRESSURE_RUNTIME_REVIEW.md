## Verified runtime behavior

- A host receives a named recipient decision to accept or refuse. The decision effect AST keeps the complete preview in `effect_tooltip` and calls the actual transaction once from `hidden_effect`. Acceptance rechecks paired pending flags, absent signed receipts, the active qualifying base agreement, bilateral eligibility, and positive GDP for both sides.
- Acceptance charges setup fees from each country's own GDP: 0.10% for the host and 0.04% for France. The signed receipt is written on both countries. Send, refusal, and treaty reconciliation do not charge either setup fee or replay construction, research, XP, or doctrine awards.
- The standing charter levy uses the host's own current GDP at 1.00% annually, divided by 52. France's receipt and the host's expense use the same seven-day cached quote, so the payer and recipient callbacks cannot value the pair from different GDP snapshots. The checker also matched 13 existing France-funded weekly-transfer rows across the accepted base agreements; each payer expense and recipient income uses the same France-GDP quote and enters the existing cooperation totals.
- The 180-day refusal freeze guards only the qualifying France-funded cash-transfer rows. Both the expense and the matched recipient income use the same freeze flag. Existing base agreements, host payment obligations, resource rights, access and guarantees remain signed. The separate 90-day host crisis applies the approved modifiers, including the numeric `interest_rate_multiplier_modifier = 0.50` change. Native MD money code adds that number to the borrowing rate; it is a 0.50 percentage-point premium while the host has debt, not new principal or a treasury transfer.
- The bilateral clear triggers require France and the partner to exist, check peace and embargo status in both countries, and check all eight directed native sanction-array combinations: diplomatic, financial, economic and military sanctions, each on and by the countries. The acceptance and timeout paths use those guards. If a pending proposal loses its paired flag or becomes ineligible, cleanup clears the pending state on both sides without creating a refusal crisis.
- Expiry of the temporary France aid-freeze flag marks both money calculations dirty so the cash rows resume. The France-owned daily treaty reconciliation suspends both charter spirits and the charter cash stream when the standing agreement is inactive, then restores them when it becomes active. Restoration does not repeat setup charges or finite awards.
- Military-access direction was checked against the installed native docs. `has_military_access_to` checks whether the current country has access to the target's territory; `give_military_access` gives the named country access to the current country's territory. For all five compiled base access clauses and all six pressure clauses, the emitted preflight checks whether the intended beneficiary (France) already has access to the grantor's territory. It creates an ownership receipt only when it grants a missing relation. Suspension removes that relation only from France's beneficiary scope and only when the receipt exists, preserving any reverse-direction access relation. The permanent receipt stays on the grantor.
- When France is absent, recipient cleanup removes its charter spirit and clears only local pending/access-ownership receipts. It does not attempt an impossible diplomatic-relation call and does not clear the permanent signed-charter receipt. When France returns, the paired receipts allow reconciliation to restore ongoing terms without charging or replaying the deal.
