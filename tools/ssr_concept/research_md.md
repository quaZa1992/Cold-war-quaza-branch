## Known reward forms and values

All cited values below are source patterns, not SSR balance recommendations.

- Native political: Generic political section uses `add_political_power` (see lines 65-243); Russia Putin path writes `SOV_putin_politic_political_power_factor = 0.05`, `...communism_drift = 0.05`, then adds `SOV_putin_politic_modifier` at lines 124-134. The custom dynamic modifier registers those variables to native `political_power_factor` and `communism_drift`, at `common/dynamic_modifiers/99_SOV_dynamic_modifiers.txt:145-151`. Modifier definition proves registration; downstream variable values still need a proper reader trace before claiming additive engine behavior.
- Native stability / war support: `add_stability = 0.05` and `add_war_support = 0.05` are direct native reward forms in Russia's Grand Bargain at line 180 and Generic examples at lines 1488 etc. Values are 0.05 native fractions, represented as +5 percentage points to the stability/war support bar.
- Research: Generic `GENERIC_submarines` grants `add_tech_bonus` with `uses = 2`, `bonus = 0.5`, `category = CAT_submarines`; lines 4429-4469. This is two 50% category research bonuses, not a permanent research-speed modifier. Microchip R&D at lines 2731-2760 instead grants 15% special-project progress if the project is not complete.
- Economy: Soviet `SOV_economy_modifier` is a registered dynamic modifier with many variable-backed effects, including research speed, industry, tax, resource/export, stability and foreign influence keys; `99_SOV_dynamic_modifiers.txt:177+`. This shows a coherent institution/economy package can be a spirit whose modifiers are variable-driven; do not treat a custom variable name as a native modifier without inspecting both registration and variable update/reader.
- Building + slot example: Generic `GENERIC_mobilize_the_working_class` (around lines 1488-1517) uses treasury change −7.5, `modify_treasury_effect`, adds one shared state building slot, then one instant industrial complex in capital, and +0.05 war support. `GENERIC_assure_the_national_fuel_reserve` around lines 2288-2307 similarly costs 3.0, grants one slot before one instant fuel silo, plus 200,000 fuel. Native patterns show slot-before-building and same-state scope.
- Treasury cost: `common/scripted_effects/00_budget_effects.txt:1482-1494` documents `modify_treasury_effect` as adding `treasury_change` to national `treasury` and refreshing money dirty variable. Generic focus examples charge values like 3.0, 7.5, and percent-of-GDP. This is a custom MD treasury API, not an engine `add_money` command. Do not call its units weekly: focus charges are one-time treasury changes. The weekly finance aggregate in target MD is `common/scripted_effects/00_money_system.txt:3681-3683`, where `cc_calculate_weekly_expense` runs and `cc_weekly_expenses` is added to `additional_expenses_rate`; this is a recurring weekly cost provider path. The project preference requires any new recurring cost literal and display in weekly MD units.

Static source alone does not prove the current live in-game modifier deactivates on party switch; inspect any cleanup/tick reconciler and current date scenario before making that claim.
