IMPERIA COLD WAR
# SSR concept v2 mechanics review

Read-only review of the current concept source. No loaded game files were changed.

## Concrete findings

1. **Fix infantry equipment target in the electronics specialisation.** `special_electronics_left` currently sets `gear('infantry', reliability=.05)` in `specialisations.py:117`. The MD archetype catalogue and infantry equipment file identify the actual target as `infantry_weapons_type` (`common/units/equipment/equipment_archetypes.md:6`, `common/units/equipment/MD_infantry_equipment.txt:4`). Use that target or remove the equipment bonus. The concept's friendly label `infantry` does not match the source category.

2. **Keep the scope of military output honest in three specialization branches.** `out` maps to `industrial_capacity_factory`, labelled Military factory output (`content.py:47-49`). The scoped equipment rewards are valid for small aircraft, medium tanks, artillery and corvettes, but the separate output modifiers affect all military factory lines. This affects `special_aircraft_left` (`specialisations.py:29`), `special_armour_right` (`:41`), and `special_artillery_right` (`:52`). Keep their category-specific equipment bonus, but describe the `out` portion as broader military production, or remove/reduce it if the branch promises only the named equipment. The CPSU State Investment and generic SSR military branch are outside this issue as requested.

3. **Equipment legacy scaling is viable only as removable idea bonuses.** The concept correctly scales positive scoped equipment bonuses to 20 percent and adverse bonuses to 75 percent (`specialisations.py:158-162`, `revision_2.py:27-30`). Native `add_equipment_bonus` examples grant persistent one-time bonuses (`common/national_focus/05_armenia.txt:9563`), so using that API would defeat the stated inheritance rule. Implement these as bonuses attached to the named modifiable Union programme spirit, then replace or modify that spirit on independence. Native idea files show scoped `equipment_bonus` patterns, including corvette and small-aircraft targets (`common/ideas/05_bulgaria.txt:136,167,186`).

4. **The market is finite by concept, not yet secured by runtime state.** The three courses each cost 0.3 to 0.5 percent of GDP once, run for 730 days, and are mutually exclusive; the two year shock gives raw growth input 1.2, civilian construction +15 percent, civilian productivity +8 percent, tax -25 percent, stability -8 points, social cost +10 percent, and consumer goods +18 percent (`market.py:5-17,55-64`). Six lots are one-use and sequential. Competitive sale returns 0.15 percent GDP against a 0.05 percent fee; worker buyout returns 0.03 against a 0.12 fee; closure returns 0.08 against a 0.03 fee and removes one actual civilian factory; public retooling costs 0.20 percent with no receipt (`market.py:29-37`). Thus the six auctions net 0.60 percent of execution-time GDP before other effects, not an unlimited income source. The one-course flag, lot receipts, 30-day interval, current-GDP weekly debit, atomic fee/receipt/building change, and persistence across government changes are still implementation requirements, not demonstrated behavior.

5. **Do not call an auction a native ownership transfer.** Auction and worker buyout preserve CIV count, while liquidation closes an `industrial_complex` level (`market.py:47-49`). The preview records finite GDP receipts and a corporate-tax modifier, but this review found no native per-factory private-ownership or sale API binding those receipts to the six named sectors. Treat auction income as a one-time GDP-priced settlement ledger and describe ownership through its charter unless implementation proves a native ownership representation. For closure, bind the selected state and actual CIV check again at execution.

6. **GDP units and the growth description are internally consistent.** Costs use country GDP fractions at execution; weekly costs use current GDP every weekly pass, with no fixed-dollar charge (`market.py:41`). `M()` divides percentage-like modifiers by 100 but keeps `productivity_growth_modifier` as a raw number (`content.py:61-62`). At neutral scalars, 1.2 adds about 0.6 state productivity points per monthly pass, or about 14.4 over 24 passes before catch-up and other growth effects (`market.py:43`). This is a flat native state-growth increment, not 120 percent annual compounding. The native tax and consumer-goods effects should continue to be previewed as a multiplier and a change to the tax-derived consumer-goods base, not percentage points of all factories.

7. **The party gates are structurally correct.** Each party focus receives `slotN` at creation (`politics.py:19-22`); the contract exposes a visible actual party name and a hidden exact MD in-power trigger (`rules.py:67-73`). The trigger table covers every slot in the current country selection, including 12, 14, 18, 20 and 21 (`rules.py:5-8`, `content.py:263-278`). The independence gate is an actual sovereign transition record, not merely an anti-communist outlook. This is sound concept intent; the actual tag change, subject checks and chosen party data still need runtime binding.

## Remaining implementation evidence gaps

The concept is not an implementation test. State assignment and legal building capacity, owned and controlled coast checks, state-slot grant ordering, party trigger wiring, timer suspension and restoration, and post-transition spirit replacement remain unverified. The navy coast list includes Caspian ports and represents regional coastal capacity; do not imply ocean-going fleet access. Independent military XP, training and doctrine discounts are institutional capability, not the creation of a sovereign force, which is a design choice rather than an unsupported modifier claim.

## Resolution in the delivered concept

The infantry target now uses `infantry_weapons_type`. Aircraft, serial-armour, volume-ordnance and defence-electronics prose identifies the broader military-production effects separately from scoped equipment rewards. All republics receive identical equipment targets and programme choices. Historical references are short terminal sentences. Specialisation weekly shares use even five-decimal units so the independent allocation can be exactly half without exceeding native precision. These source corrections are reflected in the final static and browser reports. The runtime evidence gaps above remain open because implementation is explicitly deferred until approval.
