IMPERIA COLD WAR

# France 1970 icon review

The V5 map resolves all 260 active proposal focus IDs to 37 France 1970 sprite aliases backed by Cold War focus artwork in this project: 210 retained domestic nodes and 50 named-country offer nodes. Superseded offer IDs from the 234-node concept are removed. The majority uses the France-specific `coldwar/fracoop` subfolder; remaining images are French military, regional, or diplomatic artwork from `coldwar`.

Each registered focus sprite has a matching animated `_shine` sprite. Both use the same source texture, and the shine mask points to that exact file. All selected focus textures exist in this project. The matching animated shine pairs use the stock `gfx/interface/goals/shine_overlay.dds`; the project’s other Cold War shine files reference this same path, but the overlay itself is absent from this checkout and no readable installed-game `gfx` directory was available for verification. The focus map and per-focus shine map are in `icons.json`.
