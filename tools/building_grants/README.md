## National building grants

`grants.py` provides bounded, idempotent adapters for the reviewed national
programmes in `scope.json`. It does not change MD's general construction or
investment helpers. The authoritative building definitions supply each physical
state limit.

In the 1970 start, MD's manual construction limits can be zero even when a state
contains infrastructure and has room under the building's physical limit.
Scripted instant grants therefore check the actual `building_level@type`, the
complete quantity and actual ownership/control. Shared-slot buildings and exact
province predicates keep their original native checks. Explicit research
contracts remain explicit research contracts.

The national adapters preserve each focus's complete original payload, invoice,
party requirements, predecessors, exclusions and geometry. The public preview
uses nonexecuting native effects. The actual callback checks the whole package
before applying its costs or assets, records a receipt and retries a pending
package after its requirements return. Already completed focuses in an existing
save acquire receipts without replaying their rewards.

Each building level receives one extra shared building slot in the same state,
inside the same one-time transaction, before construction. Random multi-state
grants reserve distinct owned and controlled states, prefer the home area and
use other eligible states when necessary. Flat MD helper fees respect the
country's original `skip_payment` wrapper, including calls made from a state.

`remaining.py` owns the three reviewed Syrian programmes, the consented Syrian
foreign-project delivery, the generic tree adapter and the Libyan administration
programme. The country-specific installers in `tools/building_capacity_audit`
and existing country generators retain their own original delivery contracts.

Run only the scoped installer needed for a change. A broad country generation
is unnecessary and can rewrite unrelated integrations. Each canonical emitter
applies its repair after country-specific formatting and retains the shared
runtime providers as its final output pack.

## Verification

The focused tests execute the installed alias scripts in a strict AST model,
exercise actual generated preflight and receipt guards, and check canonical
emitter retention. Unsupported statements fail closed. These tests are source
and model evidence, not a claim of a live multiplayer rehearsal.

Native 1.19.4 checks established that `collection_size` comparison operators are
strict at zero, one and two. The installed documentation's inclusive-comparison
note is inaccurate for this version. Distinct-state requirements use
`value > count - 1`.

Ordinary `instant_build = no` queues require separate native evidence. The five
reviewed Greek and Vietnamese grants use completion at the end of their focus
after native tests established that slot predicates ignore queued work and can
allow a paid order to be discarded at the state limit. Original focus duration,
money prices and building quantities are retained; additional civilian-factory
construction time is removed. This is an explicit timing change. No programme
permission technologies are installed. Private profiles, logs and engine
snapshots belong on E:.
