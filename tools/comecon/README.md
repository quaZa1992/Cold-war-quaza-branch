IMPERIA COLD WAR: Native COMECON contracts
========================================

`catalogue.json` is the approved 22-entry, 44-offer dossier export, including the final steel-extraction revision. The native compiler preserves its investment scales, host building quantities and high budgets. It supports four independent contract files, 90 funded project days followed by 90 active benefit days, and independent programmes with 180 funded active days.

Private native profiles now use `E:/HOI4_Mod_Tools/mdcoldwar/runtime/comecon`. Retained profiles were relocated to `E:/MDColdWar_Backups/Codex_Test_Archives/2026-10-25/mdcoldwar/tools/comecon/runtime`; historical reports retain their original recorded paths. `--base-snapshot` resolves within the new private runtime directory. To reuse an archived baseline, first copy that selected `native_<id>` profile there without following its asset junctions.

Build with `python tools/comecon/build.py`. Check generated structure, identifiers, encoding, references and transaction boundaries with `python tools/comecon/validate.py`. Run an isolated native transaction fixture with `python tools/comecon/engine_probe.py --minimal-startup --controller=SOV`; add `--keep-open` for native interface inspection and create a `STOP` file in the reported profile to stop that owned process. Profiles and caches stay outside the mod on `E:`. The probe freezes the generated scripts, shared integration files and artwork before launch because the engine reads its databases in multiple passes. Never edit that snapshot during the test.

The toolbar button uses the EU button's 46 x 46 donor and the same 0.9 scale and DLC-dependent offset. It occupies the next position to the right, on the same row. Only the two notification start positions in `interface/alerts.gui` are shifted to reserve space. The button can initialise COMECON on first opening in an existing save; The organisation clock also restores the safety schema in older saves. Open with the circular emblem or Shift+C.

The dossier is 900 x 580, centred and movable. The compact revision retains the approved palette, Georgia headings, Segoe UI body text, Courier New labels, rectangular programme marks, ruled fields and folder tabs. Local native BMFont atlases remove the dark outlines of the normal HOI interface fonts. No global font is changed. The source concept and its measured original coordinates remain unchanged for provenance; the latest compact layout is generated by `compact_ui.py`. `ART_NOTICE.md` and the font provenance record retain sources and rights information.

The compact dossier uses explicit page turns rather than relying on overflowing static scroll containers. The left register shows six of its eleven entries per page. Programme pages contain an overview, two offers per terms page, then a compact country-effects table. All eight initial delegations fit on one effects sheet, with country, complete numeric benefits and weekly service costs in adjacent columns. Buildings and slots share one short line; permanent resources and temporary services retain their exact values. The full native Effects preview still identifies the selected states and every effect. Expanded memberships use eight recipients per sheet. Contributions and Signatures show four delegations per page. Country pickers show six countries per page, including host pools of up to 32 members plus fourteen Union republics. Previous/next controls display their current page and total. Separate native scripted-GUI pages hide the whole inactive list. Four contract files are selected in the footer. All page choices and sliced display arrays belong to the viewing country; page turns never revise an agreement or change a contribution, vote or payment.

The cover has deterministic manila grain, paper fibres, a bound spine, staple impressions, pressure creases, mild edge wear, stacked sheets and a folded paper corner. The writing surface keeps a light, low-contrast texture. These original procedural textures are generated with fixed seeds, making subsequent builds reproducible.

Each human country keeps its own selected file and tab. The presiding delegation edits the draft programme, scale, host and Union recipient. Human Soviet control takes precedence; otherwise the first human Council member in the saved register presides. AI governments cannot propose, finance, vote, select sites or initiate membership decisions. Existing AI members remain visible as historical delegations and may receive agreed benefits as passive hosts or recipients. They pay neither capital invoices nor national programme service charges. A stock transfer requires an actual human supplier; an AI host cannot be compelled to surrender equipment. Existing nuclear eligibility requirements remain in force, including the player-only operator-safety programme.

Each human financier changes only its own offered share in five-point steps. Balance offers the remaining uncovered share from that government's own budget. No action reallocates another government's contribution. A new draft initially offers 100% from the human chair, with no charge before ratification. Other governments start at zero. The chair submits a complete draft for Council Review, sealing its price, contributions, recipients, programme and sites. Each required human delegation explicitly opens Review Terms, then signs the current revision. Passive AI recipients require no signature. Reopen Draft invalidates all previous review receipts and signatures. An actual human Union republic confirms local implementation without a Council vote. UI mutation commands carry a literal contract file ID, preventing a late command from being rerouted by another file selection.

The engine processes authoritative effects; this script does not add a separate network transport or custom background worker. Phase, authority, consent, current assets, invoices and delivery receipts are rechecked at execution. Source and isolated engine checks support these guards, but cannot establish live multi-client ordering, rehost behaviour or absence of out-of-sync errors.
Soviet republics use the existing `COLDWAR_SOV_is_union_republic` authority check. They do not join the Council array or vote separately. They can be the one actual recipient of the Soviet contribution and confirm local implementation. All fourteen native republican tags can be selected when they exist as Union republics. The allocation suspends if that Union status ends. Sites are chosen through native state-target decisions; modernisation exposes separate Site 2 and Site 3 decisions when needed. These choices remain bound to the recipient, not to whichever country opens the window.

Submission captures the human payers and actual recipients. Ratification requires the sealed review and all required current signatures. Contract terms and invoices remain fixed even if an open view is rebuilt. All capital invoices are checked before any payer is charged. A prepaid period is seven funded days or the exact shorter final period. The last invoice settles each payer's remaining liability, eliminating rounding drift. Capital is charged with the existing `modify_treasury_effect`; it is not also added to recurring budget expenses. National implementation and host support use the native weekly expense accumulator exactly once through `cc_calculate_weekly_expense` in `00_money_system.txt`.

One saved organisation clock advances four bounded daily counters. The clock is Soviet while that country exists, with a deterministic member fallback. This automatic maintenance does not authorise AI project choices. Daily controller guards pause a funded agreement if a captured financier is no longer human or if a newly human receiver has not confirmed implementation. A completely paid service period can continue for passive AI receivers. It does not scan the world or all states. Weekly partner checks iterate the captured contract countries, including actual republican recipients, and verify membership, ownership-dependent operations, bilateral war, native embargoes and the four mirrored Imperia sanction classes. Invalid operations pause funded progress and benefits; fresh prepayments stop when any payer lacks money. Weekly checks imply a maximum seven-day political suspension delay. There is no clock-bound GUI invalidation: changes to terms, funding, operating state and phase invalidate the view. Native remaining-day text follows the saved counter.

Completion checks every recipient's agreed assets before granting any. Extra shared slots are granted first in the same selected state and guarded transaction. Host levels remain one per building type; separately funded partner infrastructure retains 1 / 1 / 2 levels. Railway hubs use one deterministic existing railway junction per state, rechecked for native province capacity. Actual train deliveries use native `send_equipment` and require sufficient existing period-appropriate stock at the host. No trains are minted by execution.

Steel Extraction and Recovery grants each actual participant, including the host, +2% / +3% / +5% extraction for 90 active days plus one permanent base steel in one existing steel-producing state. The same state can receive this RGW resource improvement only once. Uranium is never added. Repeated completion cannot grant buildings, trains or steel twice. Programme suspension and reopening cannot refill the budget or duration.

Country-wide effects use one aggregate dynamic modifier, taking the strongest COMECON contribution for each modifier. State growth uses one strongest modifier per selected state. Research uses one strongest normal country idea per category. Existing national ideas, technologies and unrelated modifiers are untouched. Research support expires with the contract and cannot be banked as a later-use technology token. Nuclear support uses the existing construction, safety, upkeep and fuel modifiers. It grants neither a reactor nor nuclear technology and does not shorten the existing 1460-day fixed turnkey event.

The historical and balance provenance remains in `docs/design/COMECON_SHORT_CYCLES_PROGRAMMES.md` and its source records. Prices, 90-/180-day schedules, selectable effects and +1 state resource are explicit game abstractions, not historical contract quotations. Source validation, an isolated engine fixture, native UI inspection, real calendar/save-reload tests and live multi-client multiplayer are separate evidence levels. Current reports belong in `docs/design/comecon`; none of the first three alone proves multiplayer stability.

Safety migration uses the `cc_safety_v2` schema flag. Existing drafts discard AI funding offers and invalidate old signatures. Existing running contracts preserve their quote, paid sums, outstanding liability, recipients and funded-day progress. A legacy AI financier pauses the funded contract; its unpaid share is never reassigned to other players. Returning human control requires explicit review and approval before continuation. No automatic refund or forced cancellation is performed.

The current safety fixture runs genuine human Soviet or Hungarian native control using `--controller=SOV` or `--controller=HUN`. It exercises passive AI hosting, authority fallback, rejected AI commands, sealed quotes, stale signatures, duplicate invoices, exact paid durations, insufficient capital and an old AI-financed contract. `--base-snapshot=native_<id>` reuses an existing frozen script baseline and overlays the current feature sources. Each report records the fixture's source hashes in its profile. The legacy `native-report.json` predates the safety revision; use `native-safety-SOV.json` and `native-safety-HUN.json` for this revision. No isolated fixture creates a second human client.

The annual Council ballot and independent Catalogue supersede the earlier permanent Soviet-first editor description. See `docs/design/comecon/COUNCIL_ELECTION.md` for the current franchise, fifteen-day window, tie succession, passive AI/SSR boundaries, referral workflow and evidence limits. Run `engine_probe.py --council` to append the ballot/catalogue/referral assertions to the existing finance suite. `--council-ui --keep-open` additionally leaves a fixture electoral sheet open for native visual inspection; one invalid AI entry is injected into that sheet to inspect disabled-flag presentation, without granting that country eligibility.
