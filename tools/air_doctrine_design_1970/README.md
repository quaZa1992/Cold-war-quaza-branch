# Air Command design inputs

Requested scope: researched air-doctrine concepts with concrete values, complete inherited drawbacks and realistic 1940s-1990s precedents, including smaller air forces. This package is a design deliverable, not runtime content.

- `design.py`: five new grands, fourteen subs, complete new progression, all forty-five inherited drawback deltas, positive ceiling proposals, legal builds and historical source register.
- `build_brief.py`: read-only runtime inventory, cumulative penalty checks, known-country-modifier checks, source hashes, legal build sums and catalogue rendering. It writes no game code.
- `concept_values.json`: complete current inventory, exact proposed values and all check results.
- `docs/air_doctrine_concepts_20261029.md`: findings, rationale, native integration constraints and complete scope.
- `docs/air_doctrine_values_20261029.md`: generated activation/progression/end-state tables and the full inherited drawback schedule.

Command: `python tools/air_doctrine_design_1970/build_brief.py`.

Model evidence does not establish live modifier semantics, complete old positive-reward redistribution, equipment validity in a live designer, colour rendering, save migration, or multiplayer balance. Main MD and Paradox material retain upstream credit. Historical source authors and institutions are linked in the catalogue. Unknown individual asset permissions remain unknown. No source art or document download is redistributed.
