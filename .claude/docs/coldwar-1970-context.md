# Cold War 1970 Fork Context

Read this before any skill or agent task. It is the one home for the facts that make this
repository differ from upstream Millennium Dawn. `AGENTS.md` holds the design priorities
(human RP agency, multiplayer reliability, English-only text); this file holds the
repository facts those priorities act on.

## What this repository is

- A roleplay-first multiplayer HOI4 mod, derived from Millennium Dawn **2.0.2**
  (`descriptor.mod`: `supported_version="1.19.*"`). Humans run the important countries;
  the AI is supporting cast and fallback.
- Every `.claude/docs/` reference except this file was written for **current upstream MD**
  (2000 start, newer than 2.0.2). Treat their mechanics, file names and examples as
  leads to verify in this tree, not as facts. A file or key named in a doc may not exist
  here.

## Start date and scenario gates

- One bookmark: `COLD_WAR_1970` in `common/bookmarks/blitzkrieg.txt`, date `1970.1.1.12`,
  default country USA. `the_gathering_storm.txt` is an empty stub. There is no 2000 or
  2017 bookmark, and `*_1985*` files are retained legacy content, not a playable start.
- Gate start-specific script with `IMP_is_1970_scenario = yes`
  (`common/scripted_triggers/IMP_cold_war_scenario_triggers.txt`). Shared inherited MD
  content uses `NOT = { IMP_is_1970_scenario = yes }` to stay off at 1970.
- Country history files keep an authored `1970.1.1 = { if = { limit = { date < 1985.1.1 } ... } }`
  block. The inherited `2000.1.1` blocks remain in the same files but never execute at a
  1970 start. Do not edit them for 1970 work and do not treat their ideas, OOBs or leaders
  as the 1970 state.
- Starting armies, fleets and air wings are deliberately deferred: most 1970 blocks load
  `mdcw_1970_empty_land` / `_naval` / `_air`. Counting `division = { }` blocks gives zero
  until that work lands; size anything force-dependent from the design docs under
  `docs/<country>_1970*/` or `tools/armed_forces_1970/data`, and say so.
- The yearly dispatcher in `common/on_actions/MD_on_actions.txt` calls
  `trigger_year_[year]_events` through `meta_effect`. Only `trigger_year_2001_events` to
  `trigger_year_2030_events` exist in `common/scripted_effects/00_yearly_effects.txt`.
  Scheduling anything in 1970 to 2000 means defining the missing
  `trigger_year_<YYYY>_events` block first (in a namespaced COLDWAR effects file), then
  verifying in game that the dispatcher actually reaches it.

## Naming and file layout for new 1970 content

| Content            | Pattern (newest country work: CYP, EGY, GER, GRE, ICE, SOV, SYR)        |
| ------------------ | ----------------------------------------------------------------------- |
| Focus tree file    | `common/national_focus/COLDWAR_<TAG>_1970_focus.txt`                    |
| Focus tree id      | `COLDWAR_<TAG>_1970_focus` (ICE uses `mdcw_ICE_1970_focus`)              |
| Tree selection     | `country = { factor = 0 modifier = { add = 100 original_tag = <TAG> IMP_is_1970_scenario = yes } }` and `load_focus_tree` in the 1970 history block |
| Script ids         | `COLDWAR_<TAG>_<area>_<name>`                                           |
| Other script files | `COLDWAR_<TAG>_1970_<system>.txt` or `COLDWAR_<TAG>_<system>_<kind>.txt` |
| Localisation       | `localisation/english/COLDWAR_<TAG>_<area>_l_english.yml`, UTF-8 BOM    |
| Design notes       | `docs/<country>_1970_design/` or `docs/<country>_1970/`                 |
| Generators         | `tools/<country>_1970/` (some countries are generated; edit the source) |

Older Imperia-migrated content uses `mdcw_`, `IMP_1970_`, `ISR70_`, `USA_1970_` and
`SPR_1970_` prefixes. Do not rename it; follow the `COLDWAR_` pattern only for new work.

Inherited MD files (`05_<country>.txt`, `MD_focus_<TAG>_l_english.yml`,
`<TAG>_political_leaders.txt`, `MD_politics_view_parties_l_english.yml`) still describe
the 2000 game. Add 1970 behaviour beside them with `IMP_is_1970_scenario` gates and keep
the inherited entries as fallbacks; do not rewrite them in place.

**Generated files.** A header such as `# Generated by tools/iceland_1970/compile.py`
means the loaded file is build output. When that generator exists in `tools/`, change
the generator or its JSON source and rebuild, or the next build silently reverts the
edit. When it does not exist (archived), edit the loaded file and say so.

## Politics at 1970

- `IMP_1970_profile_*` effects and `IMP_1970_world_politics_effects.txt` set each
  country's 1970 government; `IMP_1970_has_historical_ruling_party` and
  `IMP_1970_party_name_*` files hold the starting-party labels. Their header names
  `tools/build_1970_party_localisation.py`, which is not in this checkout (archived), so
  those files are edited by hand.
- Per-country 1970 party names are added as scripted-localisation clauses gated on
  `original_tag = <TAG> IMP_is_1970_scenario = yes`, placed **before** the inherited
  clause for the same key. `docs/iceland_1970/PARTY_INTEGRATION.md` is the worked
  example.
- Leaders for 1970 are created in the history block or by a namespaced setup effect
  (`COLDWAR_<TAG>_1970_set_leader`) dispatched from
  `common/scripted_effects/00_leader_setup_scripted_effects.txt`.

## History rules for player text and research

- The world state at 1 January 1970 is the baseline. Organisations, people, treaties
  and equipment that only appear later are gated behind the event or date that creates
  them, and described only under that gate.
- Real history after 1970 is a possible outcome, not a script. Alternate branches are
  allowed and must be labelled as alternate in design notes.
- Party and leader descriptions: present tense as of their own gate. No election
  results, percentages or seat counts. A year is fine; a day only when it is the gate.

## Multiplayer acceptance

Anything that touches another player's country needs the two-client matrix from
`AGENTS.md` (concurrent actions, refusal, repeated click, pause/resume, save/reload,
disconnect/rejoin, optionally co-op). A static check or a single-player run is never
reported as an OOS or multiplayer result. Mark unrun engine and MP tests explicitly.
