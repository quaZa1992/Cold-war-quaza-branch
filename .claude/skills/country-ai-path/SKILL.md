Give one AI-run country a working AI path game rule for the 1970 start, one country per
chat. In this RP multiplayer mod the rule only steers the country while the AI runs it:
nothing it sets may limit a human who takes the country, and every state change it
causes is `is_ai = yes`.

**Syntax:** `/country-ai-path <country or TAG> [#issue]`. The country is required; an
issue number is optional. Requested arguments: $ARGUMENTS

Read `.claude/docs/coldwar-1970-context.md` first. Upstream's `ai_path_report.py`,
`apply_ai_path_weights.py` and validators are **not in this repository**: every fact
below is gathered by targeted grep, and weights are written by hand.

## Context budget

Focus trees run to 900 KB. **Never read one end to end, and never open another country's
tree to learn a shape.** Grep for ids, `ai_will_do`, `available`, `mutually_exclusive`
and `prerequisite` lines, then read only the blocks you need. Templates for every
artefact are in [references/write.md](references/write.md).

## 1. Target

Resolve the argument to a TAG: a three-letter argument is the TAG; a name is looked up in
`common/country_tags/` and `localisation/english/countries_l_english.yml`. No argument,
or an ambiguous name: ask, don't guess. If the user names an issue, read it
(`gh issue view N --repo quaZa1992/Cold-war-quaza-branch`); it goes into the PR as
`Closes #N`.

Branch `<tag-lower>-1970-ai-paths` off `origin/main`.

## 2. Facts (by hand)

Answer each and note `file:line`:

1. **Which tree loads at 1970?** The `load_focus_tree` in the `1970.1.1` block of
   `history/countries/TAG - *.txt`, else the focus tree whose `country` block gives TAG a
   positive weight under `IMP_is_1970_scenario = yes`, else the 1970 generic tree.
2. **Which rule exists?** `TAG_ai_behavior` in `common/game_rules/00_game_rules.txt`
   steers the inherited 2000 tree (`05_<country>.txt`), which a 1970 game never loads
   for a country with its own 1970 tree. A 1970 rule lives in
   `common/game_rules/COLDWAR_TAG_1970_rules.txt` (`COLDWAR_CYP_1970_rules.txt` is the
   existing file shape).
3. **Flag wiring.** Grep `999_game_rules_on_actions.txt`, the 1970 tree, events,
   decisions and `common/ai_strategy_plans/` for `TAG_*_FOCUS_PATH`, `has_game_rule` and
   `is_historical_focus_on`.
4. **The fork.** From the 1970 tree's `mutually_exclusive` and `available` lines and the
   design notes in `docs/<country>_1970*/`, list the real path forks and their roots.
5. **Burdens and cures.** Starting spirits and dynamic modifiers in the 1970 history
   block, and every focus, decision or event that removes or improves each.
6. **Government.** The 1970 leader setup (`COLDWAR_TAG_1970_set_leader`, `IMP_1970_profile_*`)
   and whether the roster is a dated timeline.

Then read [references/audit.md](references/audit.md) for the judgment calls.

Shapes:

- **1970 tree, modern rule only.** Retire the modern rule the way SYR was retired (rule
  block, its `999_game_rules_on_actions.txt` branch and its loc, leaving a
  `# COLDWAR_TAG: modern AI programme retired.` marker), then build the 1970 rule (§3–§5).
- **1970 tree, 1970 rule exists.** Standardise it (§3–§5).
- **No 1970 tree.** The country runs a shared or generic tree. Say so and stop unless the
  user wants a rule for that shared tree; never gate a shared tree on one country's flags.

## 3. Design

The judgment calls: which fork axis and how many options, whether each branch root is
reachable by something the AI can satisfy, whether party drift smothers the ramp, what
must be killswitched. Derive the fork from the prerequisite graph and each side's
`available`, never from the option names. Where branch structure is unclear, dispatch one
`Explore` subagent for the taxonomy; it returns the taxonomy, not file contents.

## 4. Write

Every artefact from [references/write.md](references/write.md), in the 1970 files: rule
in `COLDWAR_TAG_1970_rules.txt`, loc in the country's `COLDWAR_TAG_*_l_english.yml`,
flags in `999_game_rules_on_actions.txt` (or a namespaced on_action file the country
already owns), triggers in `COLDWAR_TAG_*_triggers.txt`, weights in the 1970 tree. If the
tree is generated by a `tools/<country>_1970/` builder, put weights in the builder's
source and rebuild.

Loc drafting and `_desc` sentence-count fixes go to a `localisation-editor` subagent.

**Defects you find are in scope.** A broken fork, a timing race between the country's own
path events, an asymmetric branch, a wrong state id, or a typo in an English string the
path events show gets fixed in the same PR, in its own commit.

**Rule standard.** Exactly `HISTORICAL` + one option per alt-history path +
`RANDOM_PATH` + `NO_PATH`, and `NO_PATH` is the `default = { }` block, listed last. The
historical option's text is literally `"Historical"`; its `_desc` carries the country's
1970s history. Player-facing names, no internal jargon, no "random" in a path name.
Every `_desc` exactly two sentences, present tense, no hard dates, `§8…§!` on party
names. Reuse `RULE_OPTION_MD_RANDOM_PATH` / `RULE_OPTION_MD_NO_PATH` and their `_DESC`s.

**Wiring.** Rule → `set_global_flag = TAG_<PATH>_FOCUS_PATH`. `RANDOM_PATH`'s
`random_list` includes the historical bucket; `NO_PATH` gets no branch. Gate on
`has_global_flag`, never `has_game_rule`, everywhere. Verify `NO_PATH` leaves a working
AI: a sane focus `ai_will_do` base and no dead strategy plan.

**Historical government.** On a dated 1970s timeline, write the walker
([references/write.md](references/write.md) §8). Its dates need `trigger_year_197x_events`
blocks, which do not exist yet (context doc); add them in a namespaced effects file and
say so in the PR. On an undated roster, write nothing and say so.

**AI hardening pass**, mandatory. `ai_is_threatened` weighting on combat-capacity
focuses (`.claude/docs/ai-strategy-reference.md`, "Threat and unit caps"); bankruptcy /
`can_staff` guards on spending focuses. The pass lives in focus weights, `available` and
guards only: **write no `common/ai_strategy/` war block**. Under historical AI the AI
sticks to history: killswitch non-historical branch roots, boost the historical branch.
Never script an AI country into war with a country a human runs; that is the humans'
roleplay to decide.

The country must stay able to fix itself: every starting burden keeps a live cure in
every rule state you leave standing. Where the only relief is a player-only GUI or an
`is_ai = no` decision, give the AI the same outcome through an `is_ai = yes`
`COLDWAR_TAG_ai_path_category` decision.

## 5. Verify

By hand: every rule option sets exactly one flag; no surviving `has_game_rule` reader;
every path modifier multiplicative and last in its block; no orphaned child under any
rule state × historical AI on/off; every burden has a live cure per state; no AI-only
decision or category has loc keys. Then the static checker on every touched file and
`git diff origin/main --stat -- common/ai_strategy/` must be empty.

## 6. Finish

Changelog: one line under the current version's `AI:` (or `Content:`) section,
` - [TAG] Added 1970 AI path game rule: Historical / <paths> / Random Path / No Path.`

PR body in the `/open-pr` BLUF format: `## Bottom line` with the player-visible outcome
(what the AI does under each option, and that human-run countries are unaffected), then
`Closes #N` when given, then `BLUF`. Under ten lines. Create the PR as a draft, or update
the existing one, and report the URL. State "not tested in game".

## House rules

- **Zero comments** in every file you touch, except the one-line retirement marker.
- Don't copy older shapes from countries converted before this standard.
- `git diff` before the PR and revert anything out of scope, including whitespace noise.
