# Cold War 1970 content

Read `.claude/docs/coldwar-1970-context.md` before editing. New 1970 work uses
`COLDWAR_<TAG>_` names, `IMP_is_1970_scenario` gates and English-only
`localisation/english/` files; history edits go in the `1970.1.1` block, never the
dormant `2000.1.1` one. A header naming a `tools/` builder means the file is generated:
edit the builder. Anything acting on another country follows `hoi4-rp-multiplayer` and
`hoi4-rp-diplomacy` in `.agents/skills/`.
