# UN System

Read `.claude/docs/un-system-reference.md` before editing UN voting, elections, or
recognition. It documents the invariants these files must preserve, the SC/GA vote-type
catalog, and how to add a new resolution type without making it randomly proposable.

It describes current upstream MD. In this 2.0.2 fork `15_mun_on_actions.txt` is an empty
stub and some files it names are missing, so verify each invariant against the files
above first. In 1970 the Security Council and General Assembly differ from 2000 (for
example the China seat before October 1971), and a vote between human countries is
roleplay the players must be able to see and answer.
