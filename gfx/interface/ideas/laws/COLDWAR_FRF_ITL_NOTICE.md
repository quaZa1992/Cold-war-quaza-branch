# IMPERIA COLD WAR — French Franc and Italian Lira currency artwork

Assets: `COLDWAR_french_franc.dds` and `COLDWAR_italian_lira.dds`.

Original new images: generated with OpenAI's built-in Imagegen tool for this user request. The unchanged selected PNG masters are retained in `tools/frf_itl_currencies/source/`. Exact prompts, style reference and generation receipts are recorded in that folder's parent `generation.json` and `generation_receipts.json`.

Style reference: the existing native Swiss-franc icon, retained as `tools/historical_currencies/source/swiss_frank_original.png`. Original reference-icon author/credit: unknown. Applicable reference-art licence or redistribution permission: unknown. This project marker does not assert ownership of the source reference or replace its licence.

Modifications and packaging: Codex fitted the generated coins into the existing 72×64 native currency frame, preserving transparent alpha and encoding lossless BGRA/A8R8G8B8 DDS. No repainting, visible watermark or ownership label was added to the artwork. Source and output hashes appear in `tools/frf_itl_currencies/asset_manifest.json`; reproducible packaging is in `build_icons.py`. The PNG previews in `tools/frf_itl_currencies/previews/` derive from the same assets.
