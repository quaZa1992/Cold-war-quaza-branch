# Cold War land doctrine icons

Fourteen original transparent icons generated by the built-in OpenAI ImageGen tool, directed by Codex at the user's request. Existing Millennium Dawn doctrine pictograms were supplied as style references. Their individual artists and separate redistribution permissions are unknown. The full prompts, generation paths, retained masters, source credits, unknown licence information and hash manifest are recorded in `tools/doctrine_expansion_1970/NOTICE.md` and its companion JSON records.

The runtime textures are 64 x 64 uncompressed BGRA32 DDS with transparency. Export changes only transparent margins, proportional scale, centering and file encoding. No visible watermark is added. The project identifier does not claim ownership of the existing reference artwork or establish a licence for third-party material.
