# Air Command doctrine pictograms

Nineteen original transparent pictograms generated with OpenAI's built-in ImageGen tool, directed by Codex for the user. Runtime files are 64 x 64 BGRA32 DDS with transparent backgrounds.

Exact prompts, original sources, hashes, style references, credits, unknown separate reference permissions and conversion steps are recorded in `tools/air_doctrine_implementation_1970/NOTICE.md`, `imagegen_sources.json` and `icon_manifest.json`. Original masters remain in that tool folder. Only transparent-bounds cropping, proportional downscaling, centering and DDS encoding were applied.

Style references originate in existing Millennium Dawn aircraft doctrine art. Individual original artists and separate redistribution permissions are unknown. Existing MD and Paradox rights remain unchanged; the project identifier grants no third-party rights.
